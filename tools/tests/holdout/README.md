# tests/holdout — сейф (RSI-002)

Закрытый набор для проверки на приёмке. **Его пишет человек, не агент.**

## Зачем

У нас агент сам пишет eval и сам по нему проверяется — классическая петля закона
Гудхарта: метрика начинает измерять способность угадать тест, а не пользу. Holdout —
тот кусок проверки, который оптимизатор не видит, поэтому «подкрутить под тест» нельзя.

Источник правила: разбор видео «Как я научил своих AI-агентов улучшать себя каждый
день» (Мысли Рвачева, 10.11.2026), правило «сейф для проверки»;
`ACTIVE_TASKS.md` → секция `RSI`, задача **RSI-002**.

## Правила

1. Агент **не читает** эту папку при оптимизации промптов, скиллов, моделей, ядра.
2. Агент **не пишет** сюда кейсы и не правит `expected_*`. Только человек.
3. Прогон — **только на приёмке**: `bash tools/eval_gate.sh --holdout`.
4. Каждый кейс: `split: "holdout"` и непустой `reviewed_by`.
5. Пустой сейф = **провал** гейта, а не «зелёно». Так честнее.

## Формат

JSONL, одна строка — один кейс, схема как у видимого набора
(`tools/rag_evalset.py`). Отличие — поле `split`.

Шаблон: `_example.jsonl.template` (намеренно **не** `.jsonl`, чтобы не попал в гейт
до того, как человек заполнит `reviewed_by`).

```json
{"id":"hold-001","query":"...","scenario":"paraphrase","answerability":"answerable",
 "expected_document_ids":["doc-1"],
 "gold_evidence":[{"document_id":"doc-1","section_id":"s1","relevance":2}],
 "expected_facts":["..."],"reviewed_by":"igor","split":"holdout","dataset_version":"2026-11-17"}
```

## Как наполнять

- 5–10 кейсов на первый заход, не больше: сейф нужен работающий, а не большой.
- Кейсы брать из **реальных провалов** (жалобы, приёмка «не то»), а не придумывать.
- Держать отдельно от `visible`: если кейс стал видимым (попал в промпт, в примеры,
  в документацию скилла) — он сгорел, заменить новым.
- Ротация: раз в N приёмок часть сейфа раскрывается и заменяется свежей.

## Проверка

```bash
python3 tools/holdout_gate.py --dry-run   # что видит гейт
python3 tools/holdout_gate.py             # валидация сейфа
bash tools/eval_gate.sh --holdout         # то же через общий гейт
```
