## Вызов
```
/finish-day
```

## Что делает
```bash
bash /Users/igorvasin/freelance-2026/tools/ops/finish_day.sh
```

- Перед закрытием проекта или сменой контекста
- Нужно зафиксировать текущие изменения в Git
