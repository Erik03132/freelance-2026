# /start-day

Начало рабочей сессии — читает контекст предыдущей сессии, проверяет серверы, ботов и API ключи.

## Вызов
```
/start-day
```

## Что делает
Запускает скрипт `tools/ops/start_day.sh` который:

1. Показывает дату и заголовок сессии
2. Читает последние записи из `SESSION_LATEST.md` — что было сделано вчера
3. Читает `ACTIVE_TASKS.md` — какие задачи активны
4. Читает первые строки `chp.md` — общий контекст проекта
5. Показывает `git status` — что изменилось в репо
6. Проверяет PM2 — работают ли серверы и боты
7. Проверяет ключевые порты (3000, 8080, 8000, 3001, 11434, 9200) — всё ли up
8. Проверяет API ключи в `.env` — не протухли ли
9. Выводит рекомендуемые следующие шаги

## Когда использовать
- В начале каждой рабочей сессии в ZCode или Open Code
- После перезапуска системы
- Перед началом работы над новым проектом — убедиться что всё в порядке

## Пример
```
/start-day
```
Результат — полный отчёт о состоянии среды, готовности серверов и ключей.
