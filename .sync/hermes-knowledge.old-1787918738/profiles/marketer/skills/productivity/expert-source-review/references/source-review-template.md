# Шаблон вердикта (4 абзаца)

```markdown
**Что это.** <Одно предложение: что за штука, на чём написана, сколько звёзд/активности.>

**Зачем.** <Одно предложение: какую задачу решает, кому полезна.>

**Нужно ли нам.** <Одно предложение с глаголом «берём / не берём / в очередь» + одна причина.>

**Что с этим делать.** <Либо «ничего», либо конкретный следующий шаг.>
```

**Правила:**
- Без таблиц, без списков из 6 пунктов, без «архитектурных уроков».
- Без перечисления рисков списком (юридических/лицензионных) — если важно, упомяни одной фразой в «Нужно ли нам».
- Продающее видео с общими фразами = «продающее, шум, не берём» без попыток спасти.
- Битый URL = «ссылка битая, контент недоступен, дай альтернативу».
- **Финал вердикта = жёсткий бинарный гейт.** После 4 абзацев — строка вида
  **«Принять? ДА / НЕТ»** (для ES — «брать / не брать»). ЗАПРЕЩЕНО закрывать
  мягко: «хочешь / не хочешь», «на твоё усмотрение», «рекомендую». Исключение:
  Игорь ЯВНО делегировал («полагаюсь на тебя») — тогда решай сам и действуй без вопроса.
