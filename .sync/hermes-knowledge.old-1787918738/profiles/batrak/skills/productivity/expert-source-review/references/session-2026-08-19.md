## razbor-servisa (Ntmib, 7★, MIT)

**Что это.** MIT-скилл для Claude Code, 7★/4 форка, два коммита (оба Co-Authored Opus 5). Метод из7 шагов: развилка A/B/C (есть API / кривой / нет) → реверс через F12→Network→Copy as cURL → CLI под стек проекта → Skill поверх CLI. Плюс `references/curl-to-cli.md` и `rossiyskie-osobennosti.md` (кодировки, ИНН/КПП, запятая).

**Зачем.** Превращает чужой сервис без API в маленькую CLI-утилиту, которой агент управляет сам по человеческой фразе. Полезно для интеграций с российскими сервисами (Ozon Seller, WB, Т-Банк, Mango, Bitrix24), у которых API часто кривое или отсутствует.

**Нужно ли нам.** Берём в кандидаты, не в прод. Совместим с нашим CP-1 (cli-for-agent) на 100%, и Шерлок прямо сейчас упирается в задачи «интегрируйся с X, где нет нормального API». Юридический риск: нужно ToS-чек перед прод-запуском.

**Что с этим делать.** (1) Скопировать `SKILL.md`+references в `agent-lab/references/razbor-servisa/`. (2) Добавить развилку A/B/C в `agent-lab/skills/sherl-research/SKILL.md`. (3) `agent-lab/foundation/EXTERNAL_SERVICE_RULES.md`: чтение автономно, запись через подтверждение. (4) Пилот на одном реальном сервисе (Mango или WB) — без пилота не в прод.

## watermarks-remover (guillaumemeyer, 15.1k★, MIT)

**Что это.** MIT-проект, 15.1k★/1.7k форк, 128 коммитов, активный. Снимает multi-vendor AI-провенанс с текста (Unicode+rewrite) и файлов (C2PA/EXIF/XMP). Архитектура — **skill/service split**: скилл = тонкий HTTP-клиент на curl, движок за stdlib ThreadingHTTPServer + dynamic OpenAPI 3.0.3.

**Зачем.** У нас LLM иногда лепят в выдачу невидимые символы (ZWSP, BOM, soft hyphen), которые ломают JSON/CSV/БД и эмбеддинги. Layer A из этого проекта — чистая гигиена, не anti-detect.

**Нужно ли нам.** Layer A — берём. Layer B (LLM-rewrite) и Layer C (container metadata) — этически серо (anti-detect), в прод не ставим. Архитектурно skill/service split — эталон для будущих наших интеграций по CP-1.

**Что с этим делать.** (1) Положить в `~/.hermes/skills/text-unicode-hygiene/` модуль `text_unicode.py` + обёртку inspect/clean (выполнено в сессии). (2) Забыть про Layer B/C. (3) Использовать архитектурный паттерн для будущих интеграций.

## youtube-dl-wpf (database64128, 1.4k★, GPL-3.0)

**Что это.** GUI-обёртка для yt-dlp на .NET WPF, только Windows. MVVM, тёмная/светлая тема, скачивание плейлистов, выбор форматов, субтитры, прокси.

**Зачем.** Альтернатива командной строке yt-dlp для тех, кто не хочет помнить флаги. Не наш случай.

**Нужно ли нам.** Нет. WPF = только Windows, у нас Mac. У нас уже есть `youtube-content` skill для работы с yt-dlp из терминала.

**Что с этим делать.** Ничего. Пропустить, в ACTIVE_TASKS записать как ОТКЛОНЁН (чтобы не возвращаться).
