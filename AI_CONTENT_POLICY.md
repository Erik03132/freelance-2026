# AI_CONTENT_POLICY.md — границы для AI-контента

> Документ для всей команды агентов (Hermes/Игорёк/Шекспир/Маркетолог/Кулибин/...).
> Применяется **везде, где контент уходит к людям**: лендинги, посты, статьи, письма, скрипты продаж, коммерческие предложения.

## 1. Железные правила (не обсуждаются)

1. **Не выдумывать факты.** Нет источника — нет утверждения. Цифра, имя, дата, цитата — всё проверяется перед публикацией.
2. **Не называть конкурентов по имени в негативном ключе.** Можно описать их подход (абстрактно). Нельзя «X — плохой, потому что...».
3. **Не обещать то, что не контролируется:** «заработаешь X рублей», «найдём Y клиентов», «гарантированный результат за Z дней».
4. **Не выдавать LLM-вывод за врачебную/юридическую/финансовую консультацию.** Каждый медицинский/правовой/налоговый текст имеет disclaimer.
5. **Не трогать чужие бренды, торговые знаки, лицензии без явного права.** Цитаты — с указанием источника и в объёме fair use.

## 2. Стиль и тон

1. **Писать как умный собеседник, не как лендинг.** Запрещено:
   - «stands as a testament», «vital role», «broader movement», «evolving landscape»
   - «nestled in the heart of», «breathtaking», «vibrant»
   - Цепочки из 3+ em-dash в одном предложении
   - «delve into», «leverage», «unlock the potential»
   - Стоковый финал «whether you're a X or Y»

2. **Соблюдать voice из брифа.** Если клиент хочет «по-человечески, без корпоратива» — никакого «мы рады предложить вам».

3. **Сокращать, не раздувать.** Лучше 5 коротких предложений, чем 1 длинное. Лучше 1 пример, чем 3 общих слова.

4. **Числа и факты — конкретные.** Не «много», а «47 клиентов за Q2 2026».

## 3. Структура (для лендингов и длинных текстов)

1. **Заголовок** = главная ценность для читателя (не про нас).
2. **Первый абзац** = проблема читателя (не «мы предлагаем»).
3. **Средняя часть** = как решаем (с примерами, цифрами, кейсами).
4. **Финал** = следующий шаг (что делать читателю прямо сейчас).

## 4. Дисклеймеры (шаблоны)

### Медицина (для Айболита и всего медицинского контента)
```
Это справочная информация, не медицинская рекомендация.
Перед изменениями в лечении — консультация врача.
Источники: [ссылка на каждую цифру/факт]
```

### Инвестиции/налоги
```
Не является инвестиционной/налоговой рекомендацией.
Решение принимается на основе собственного анализа
или консультации с профильным специалистом.
```

### Прогнозы
```
Прогноз основан на данных [период]. Реальные результаты
могут отличаться в зависимости от рынка, конкуренции,
команды и других факторов.
```

## 5. Процесс перед публикацией

1. **Черновик** — агент пишет.
2. **Проверка фактов** — `grep` по источникам, верификация каждой цифры.
3. **Humanizer** (скилл) — финальный проход от AI-маркеров.
4. **Одобрение владельца** (Игорь) — для всего, что уходит к клиенту/публике.
5. **Публикация** — после одобрения.

**Без одобрения владельца не публиковать, не отправлять, не озвучивать клиенту.**

## 6. Что НЕ считается AI-контентом

- Код, JSON, YAML, SQL — там стиль другой, важна точность
- Внутренние файлы (ACTIVE_TASKS.md, docs/, ADRs) — там читает Игорь, не клиент
- Личные заметки в Obsidian (private/) — не публикуются
- Технические спецификации для разработчиков

## 7. Ответственность

- **Шекспир** — основной автор контента. Перед сдачей прогоняет humanizer.
- **Маркетолог** — пишет лендинги/продающие тексты. Тот же humanizer + проверка структуры.
- **Hermes (Chief)** — финальное ревью для коммерческих предложений >100к₽.
- **Игорь** — финальный одобряющий.

Если сомневаешься в серой зоне — спроси Игоря. Не угадывай.
