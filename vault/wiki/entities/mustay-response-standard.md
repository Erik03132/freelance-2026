# Стандарт откликов Batrak v3 (HOOK-MATCH-PROOF)

Источник: `06-Library/mustay-response-patterns/digest.md` (2026-08-23), проект `hh-ai-agent` / Mustay. Связанные документы по ссылкам дайджеста: `04-Decisions/2026-08-23-batrak-v3-response-standard.md`, `03-Lessons/2026-08-23-batrak-response-lessons.md`.

## Принцип: ценность до контракта

Вместо резюме — мини-консалтинг. Четыре шага:

1. Зафиксировать истинную потребность (explicit request).
2. Назвать 2 скрытых риска (рост расходов на LLM, узкие места API, галлюцинации).
3. Предложить зрелую архитектуру (FSM, Pydantic, гибридный RAG, очередь retry, Smart Fallback).
4. Задать 2 квалификационных вопроса клиенту.

## Формула письма

```
[Приветствие] Здравствуйте!
[HOOK — 1 предложение] боль клиента или подтверждение профильного опыта в стеке
[MATCH — 2–3 абзаца] архитектурные гарантии: A2A-диспетчеризация,
   гибридный RAG, Pydantic-валидация, защита от сбоев, Docker 24/7
[PROOF] ссылка на открытый репозиторий с кодом и кейсами
[Подпись] С уважением, Игорь
```

## Банк формулировок

Для AI/RAG/агентов:

- гибридный RAG (эмбеддинги + dense search + reranker) с замером Hit@k и MRR;
- cost-aware маршрутизация LLM (Tier-0 / Tier-1 / Fallback) для снижения себестоимости и задержек;
- архитектура в ADR плюс eval-тесты на бизнес-логику.

Для Telegram-ботов и CRM (Bitrix24 / Mango):

- FSM-сценарии на aiogram с валидацией обязательных полей через Pydantic и Smart Fallback (бесшовный перевод на оператора);
- асинхронные очереди повторов для передачи сделок в Bitrix24 REST API без потерь лидов на пиках;
- Docker-контейнеры с автоперезапуском и мониторингом 24/7.

## Стоп-лист

«Доброго времени суток», «Готов взяться за ваш проект / ищу работу», «Рассмотрите мое резюме», «Сделаю быстро и качественно» (пустые обещания без инженерной фактуры).

## Как это связано с остальным

Формулировки про гибридный RAG, cost-aware роутинг и eval — обещания, которые должны подтверждаться кодом (eval-слой, Tier-роутинг). Если в проекте этого нет, использовать фразу нельзя: это уже не копирайтинг, а ложь в оффере.

## Ограничение

Дайджест — внутренний стандарт, не исследование. Эффективность формулы (конверсия откликов) в нём не измерена.
