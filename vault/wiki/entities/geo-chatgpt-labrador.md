# GEO под ChatGPT: робот labrador и карточка на 200 символов

Источник: `06-Library/geo-chatgpt-2026/digest.md` (2026-08-20), статья Habr (gottivartanian), база ~1,9 млн источников ChatGPT за фев–июль 2026 (браузерный и API каналы). См. также `sources.md`.

## Главное

ChatGPT не ходит в Bing и не гуглит: у него свой поисковый робот (внутреннее имя `labrador`), он даёт 97% всех источников. Между сайтом и ответом стоит посредник — карточка ~200 символов (заголовок + описание); по ней модель решает, годится ли страница. Страницу целиком в момент ответа модель не читает.

## Анатомия карточки

- Описание ровно ~200 знаков (99,9% — 195–205), обрывается многоточием на полуслове.
- 61% описаний начинаются с H1 страницы в ВЕРХНЕМ РЕГИСТРЕ.
- Заголовок не режется (как в поисковиках на 60–70 знаках): треть длиннее 75 знаков, рекорд — 1124.
- Дата публикации известна у 56% страниц.
- Охват — 12 035 разных сайтов, включая мелкие региональные и отраслевые.

## Покупная выдача (3% карточек)

Конвейеры `bright` / `oxylabs` / `serp` — перепроданные результаты внешних поисковиков. Признаки: описание ~155 знаков, заголовок обрезан на 70, даты нет, 23% начинаются с «Dec 10, 2025 … Read more». Доля по площадкам, которые блокируют чужих роботов: Instagram 100%, Pinterest 100%, YouTube 88%, LinkedIn 74%, Reddit 43%.

## Это не Bing: доказательство из логов

Два потока не смешиваются. Из 2500 ответов 2343 целиком на собственном роботе, 71 целиком на покупной, смешанных нет. Сайты разные: 12k против 318 доменов, общих 175. Переключение идёт на весь ответ, а не «добрали у поисковика».

## Что делать

1. H1 критичен: он попадает в начало карточки капсом. Чёткий содержательный H1 с ключевыми словами.
2. Первые ~200 символов страницы — снапшот, по которому решают. Суть сразу, без вводной воды.
3. Держать дату публикации/обновления актуальной и машинно читаемой (schema/метаданные).
4. Свой открытый сайт важнее соцсетей: закрытые площадки докупаются и видны хуже (обрезанный заголовок, без даты).
5. Жёсткого лимита длины заголовка нет — содержательность важнее размера.

## Границы применимости

Цифры — из одного замера (~1,9 млн источников, фев–июль 2026), не из документации OpenAI. Механика карточки описана автором по логам, не подтверждена вендором. Для решений «как писать страницу» годится; как гарантия попадания в ответ — нет (см. `geo-yandex-alisa` о разнице механик).
