# Технический SEO на масштабе: Python вместо Excel

Источник: `06-Library/seo-ecommerce-automation-2026/digest.md` (2026-08-20), кейс Habr (aleksey-malafeev, ex-Детский мир, ex-Магнит Маркет): сотни тысяч — миллионы страниц.

## Точка входа

Выгрузка проиндексированных страниц перестала влезать в один лист Excel (лимит 1 048 576 строк). Power Query хватало до появления потребности в истории, регулярных проверках и сопоставлении источников. Эволюция стека: Power Query → Python + SQL → API → дашборды (Yandex DataLens, Power BI) → ИИ-инструменты для точечных задач.

## Четыре блока автоматизации

1. **Сортировка URL по типам страниц** — regex по структуре URL (category/filter/brand/product). При массовой проблеме сразу видно, какой тип страниц её порождает, и можно гасить очаг.
2. **Приоритизация ошибок из GSC Pages** (редиректы, 404, canonical): скрипт считает тип страницы / количество / долю входа → первым разбирается самая проблемная доля.
3. **Дашборд трафика по типам страниц**: Метрика API → классификация regex → BI. Ловит эффект релиза, когда общий трафик не изменился, а внутри один тип вырос, другой просел.
4. **Мониторинг sitemap.xml**: ежедневный парсинг в БД, URL = primary key, даты первого/последнего появления. Внезапное исчезновение тысяч товарных страниц коррелирует с ростом excluded в GSC → причина в шаблоне генерации, а не в ассортименте.

## Автотесты

Проверять каждую страницу на миллионах URL бессмысленно. Берут репрезентативные страницы из каждого типа и регулярно гоняют: заголовки, ссылки, наличие текста, плитка товаров. Свой Python-набор проще, чем ставить задачу на разработку.

## Нюанс про ИИ

Разовую обработку списков в сотни/тысячи строк ИИ сделает. Для регулярной работы с миллионами URL нужна воспроизводимость: сохранять, сравнивать, встраивать в мониторинг. Маленький debuggable Python-скрипт здесь лучше агентного промпта.

## Что забрать

- sitemap-мониторинг — прямая база под скилл `sitemap-audit`: ежедневный парс + история + алерты на выпадения.
- Классификация URL по типам через regex — паттерн для `seo-audit`: разбивать проблемы по типам, не валить в кучу.
- Дашборд «трафик по типам» — метрика успеха SEO/GEO: видно срез по типам, а не общий трафик.
