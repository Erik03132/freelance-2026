# Речевая аналитика как автономный агент (BSS 2.15)

Источник: `06-Library/books/20260813_bss--_-_-----_----215/digest.md` (read 2026-08-15), обзор релиза 2.15 продукта «Речевая аналитика» BSS.

## Что изменилось

Продукт перешёл от реактивного инструмента к проактивному агенту: по расписанию сам анализирует записи звонков и рассылает инсайты, без запроса пользователя. Это тот же сдвиг, что в `agentic-ai-guide` — от «вызвали и посмотрели» к «работает по триггеру».

## RAG в оценке качества

RAG встроен в автоматические оценочные карты: поиск по внутренним базам знаний плюс генеративная модель для семантического контроля качества. То есть оценка идёт не по жёсткому списку слов, а по смыслу относительно корпоративных регламентов.

## Модули контроля качества

- Гибкий семплинг: оценивается не всё подряд, а выборка.
- Виджет «Дерево маркеров»: иерархия признаков разговора.
- Отчёт «Распределение оценок».
- Справочники обратной связи.

## Агент-Тренер

Многоуровневая оценка (иерархический скоринг с критическими целями, способными останавливать симуляцию), языковая настройка, объяснение результатов, дашборд ученика. Плюс рефакторинг UX/UI.

## Что отсюда переносится (интерпретация, не факт источника)

1. Оценка звонков по смыслу через RAG по регламентам — тот же приём, что нужен для проверки качества голосовых агентов Levitan/AVM, где сейчас нет eval-слоя на транскриптах.
2. Иерархия маркеров с критическими целями важнее среднего балла: один стоп-фактор (грубость, неверная цена) должен обнулять оценку, а не тонуть в сумме.
3. Семплинг вместо тотальной проверки — единственный способ держать стоимость на потоке звонков.

## Границы

Один вендорский обзор релиза, без независимых замеров и без цифр качества. Как источник паттернов годится, как доказательство эффективности — нет. Прямой связи с нашим стеком в дайджесте нет.
