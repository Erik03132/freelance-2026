# Противоречия и расхождения источников

Только то, что реально расходится в `06-Library`. Где расхождение мнимое (разные знаменатели, разные версии) — так и помечено.

## 1. llms.txt: два дайджеста одной статьи с разной точностью

- `books/llms-txt-habr/digest.md` (2026-08-10): «408 обращений из ~515 млн бот-событий за 90 дней», «менее 0.0001%».
- `books/20260809_llmstxt-_-----------__x2f_-/digest.md` (read 2026-08-15): «<0,001 % от всех bot-событий».
- Пересчёт по первым данным: 408 / 515 000 000 ≈ 0,000079% — оба утверждения истинны, но второе в 12 раз грубее. Дубликат мог разъехаться при генерации.
- Как читать: цифру брать из `llms-txt-habr` (там же указан первоисточник Limy.ai, май 2026); второй файл считать копией.

## 2. skill-library-v2: план 2026-08-23 против фактического состояния

- `skill-library-v2/digest.md` (2026-08-23): федеративная библиотека по тегам, sync worker cron 03:00 MSK, кеш в `~/.hermes/profiles/personal/cache/skills/`, установка через `npx skills add coreyhaines31/marketingskills`, «Next steps» — построить мост в `projects/skill-library-bridge/`.
- `skills-catalog/catalog.json` (2026-11-16): `{"skills": []}` — каталог пуст. Моста и синка нет.
- `gh-weekly-2026-10-20/digest.md` (2026-10-20): `npx skills add` упал с E407 (перехватывающий прокси), скиллы ставили вручную через `git clone --depth 1`; набор собран из `mattpocock/skills`, а не из `marketingskills`.
- Вывод: страница `skill-library-v2` — это проект, а не работающая система. На октябрь скиллы ставились вручную локальными папками (см. `oss-weekly-2026-10`), а не через каталог.

## 3. ElevenLabs Realtime: кому запрещён ZRM/HIPAA — расхождение внутри одного файла

- `eleven-realtime-2026/digest.md` (2026-10-25), таблица: строка «Режимы» у **Max** — «token limit ≥1024 или без лимита; NOT в ZRM/HIPAA».
- Там же, список «Умолчания дропа», п.2: «**Mini** недоступна в Zero Retention Mode / HIPAA».
- Один и тот же файл указывает ограничение и на Max, и на Mini. До проверки у вендора нельзя утверждать, что ZRM/HIPAA есть хотя бы у одной версии.
- Как читать: для обзвона с ПД это стоп-фактор у обеих версий, пока не подтверждено обратное.

## 4. Cua: «открытый слой» против лицензии FSL

- `cua-spaces-sdk-2026/digest.md` (2026-10-25): в главном выводе — «открытый слой», «cua ничего не рентует».
- Там же, «Умолчания дропа»: driver — MIT, **Spaces app — FSL-1.1-MIT** (source-available, запрет конкурирующих продуктов 2 года).
- Это не противоречие по смыслу, но по формулировке: FSL — не OSI-open-source. Для внутреннего использования ок, для клиентского продукта — проверять.
- Там же отдельная граница безопасности: правила Space — «инструкции, не enforcement», host-доступ не давать.

## 5. Голосовой стек: решение от 23.09 не пересмотрено после 25.10

- `tools/vapi-voice-ai/digest.md` (2026-09-23): для массового обзвона (100+ звонков/день), кастомной SIP-логики, on-prem/РФ — «оставить текущий стек Mango + LiveKit + pipecat».
- `eleven-realtime-2026/digest.md` (2026-10-25): end-to-end Speech-to-Speech становится «новой единицей роутинга» вместо ручной сборки STT→LLM→TTS; сильная сторона — turn-taking (перебивания, «угу»), то есть ровно боль Levitan.
- Формального противоречия нет (разные продукты), но вывод «оставить как есть» старше на месяц и не учитывает STS-класс. При следующем решении по AVM перечитывать оба, а не только Vapi-дайджест.

## 6. ChatGPT: «97% источников» против «70% ответов» — разные метрики

- `geo-chatgpt-2026/digest.md` (2026-08-20): собственный робот `labrador` даёт **97% всех источников** ChatGPT.
- `geo-yandex-alisa-2026/digest.md` (2026-08-20): «Источники даёт в 99% ответов (ChatGPT — 70%, остальные — редко)».
- 97% — доля источников внутри ответа; 70% — доля ответов, где источники вообще есть. Оба числа могут быть верны одновременно.
- Как читать: не смешивать в одном утверждении; при цитировании указывать базу.

## 7. Не противоречия, но требует проверки перед использованием

- **Звёзды репозиториев.** `skill-library-v2` — marketingskills «60k+ stars»; `gh-weekly` — mattpocock/skills «298k★», hyperframes «68.2k★», openrig «8k★». Разные репозитории, поэтому не конфликт, но ни одно число не перепроверялось в рамках вики.
- **Одно имя — два пакета.** `books/20260808_notebooklm-mcp-_-pypi/digest.md` (FastMCP v2, STDIO/HTTP/SSE, Taskfile 20+ задач) и `books/20260808_github---jacob-bd_gemini-notebook-mcp-cli_.../digest.md` (`nlm` CLI + MCP, ~43 инструмента, миграция с устаревших пакетов) описывают «notebooklm-mcp» по-разному. Вероятно, один проект в разных версиях, но по дайджестам это не доказать: перед установкой смотреть репозиторий.
- **Повреждённый источник.** `sinergy-expert-council/digest.md` (2026-08-23) потерял кириллицу (в файле читаются только латиница, цифры и структура). Факты о пайплайне Sinergy в вики взяты только из уцелевшего; остальное — в `04-Decisions/2026-08-23-sinergy-expert-council-pipeline.md` (не читалось в рамках HMS-1).
- **Каталог библиотеки неполон.** `06-Library/_catalog.md` (2026-11-16) перечисляет только `books/` и 4 дайджеста; папок `tools/`, `geo-*`, `gh-weekly`, `cua`, `eleven`, `seo-*` в нём нет. Опираться на каталог как на перечень источников нельзя.
