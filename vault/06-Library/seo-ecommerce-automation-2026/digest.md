# Автоматизация SEO крупного e-commerce: от Excel к Python (2026)
Источник: Habr, aleksey-malafeev (Senior SEO, ex-Детский мир, ex-КазаньЭкспресс/Магнит Маркет).
Кейс: сотни тысяч — миллионы страниц, много URL/параметров/регулярных изменений.
**См. также:** [[geo-yandex-alisa-2026]], [[geo-chatgpt-2026]] — это GEO (видимость в ИИ); здесь же технический фундамент под неё.

## Точка входа
Выгрузка всех проиндексированных страниц перестала влезать в 1 лист Excel (1 048 576 строк).
Power Query хватало сначала, потом — нет: нужна история, регулярные проверки, сопоставление источников, авто-результаты.
Эволюция стека: Power Query → Python + SQL → API → дашборды (Yandex DataLens, Power BI) → + ИИ-инструменты для точечных задач.

## 4 прикладных блока автоматизации
1. **Сортировка URL по типам страниц** (regex по структуре URL: category/filter/brand/product…).
   Зачем: при массовой проблеме — сразу понять, какой ТИП страниц её порождает, погасить «очаг».
2. **Приоритизация ошибок из GSC Pages** (редиректы, 404, canonical).
   Скрипт: тип страницы / кол-во / % от входа → разбирать в первую очередь самую «проблемную» долю.
3. **Дашборд трафика по типам страниц** (Метрика API → классификация regex → BI).
   Ловит эффект релиза: общий трафик не изменился, а внутри один тип вырос, другой просел. Точка для анализа «что случилось».
4. **Мониторинг sitemap.xml** — ежедневный парсинг в БД. URL = primary key, даты first/last появления.
   История изменений: внезапное исчезновение тысяч товарных страниц ≠ кончился товар. Коррелирует с ростом
   excluded в GSC → причина в шаблоне генерации, а не в ассортименте.

## Автотесты
На миллионах страниц проверять каждую — бесполезно. Берут **репрезентативные страницы из каждого типа**
и регулярно гоняют: заголовки, ссылки, наличие текста, плитка товаров. Проще свой Python-набор, чем ставить задачу на разработку.

## Нюанс про ИИ
Списки в сотни/тысячи строк ИИ-инструменты обработают сами (напишут скрипт/обработают файл).
НО для РЕГУЛЯРНОЙ работы с миллионами URL нужна воспроизводимость: сохранять, сравнивать, встраивать в мониторинг.
→ Маленький Python-скрипт здесь удобнее ручной работы с ИИ. (Совпадает с нашим принципом: предпочитаем
debuggable CLI-скрипты агентным промптам там, где нужна повторяемость.)

## Что забрать Маркетологу / нашим скиллам (sitemap-audit, seo-audit)
- sitemap-мониторинг = прямая база под наш `sitemap-audit` skill: ежедневный парс + история + алерты на внезапные выпадения.
- Классификация URL по типам через regex — паттерн для `seo-audit`: разбивать проблемы по типам, не валить в кучу.
- Дашборд «трафик по типам» — метрика успеха GEO/SEO работы (видим не общий, ассорт, а срез по типам).
