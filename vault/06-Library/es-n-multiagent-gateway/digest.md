## 1. Карта ролей 6 экспертов Совета (Expert Council)

| Эксперт | Профиль | Фокус и зона ответственности |
|---|---|---|
| **Femida** | `femida` | Право, договоры, NDA, риски 152-ФЗ / GDPR, тендеры 44/223-ФЗ |
| **Defender** | `defender` | Безопасность, .env, утечки, OWASP, проверка зависимостей, PII |
| **Marketer** | `marketer` | Позиционирование, офферы, SEO/GEO/AEO, воронки, копирайтинг |
| **Financier** | `financier` | Юнит-экономика, смета, ROI, риски неоплаты, ценообразование |
| **Sherlock** | `sherlock` | Анализ рынка, конкурентов, валидация гипотез, поиск вакансий |
| **Health** | `health` | MedTech, эргономика, режим труда, стресс-тест ограничений |

## 2. Формула вызова Совета (Council Execution Pattern)

### Параллельный опрос через `delegate_task`:
```python
delegate_task(tasks=[
  {"goal": "Оценить рыночную перспективу и спрос", "context": SOUL_SHERLOCK + data, "role": "leaf"},
  {"goal": "Оценить юридические риски и требования 152-ФЗ", "context": SOUL_FEMIDA + data, "role": "leaf"},
  {"goal": "Проверить безопасность архитектуры и данных", "context": SOUL_DEFENDER + data, "role": "leaf"},
  {"goal": "Оценить упаковку, позиционирование и каналы", "context": SOUL_MARKETER + data, "role": "leaf"},
  {"goal": "Просчитать юнит-экономику, бюджет и ROI", "context": SOUL_FINANCIER + data, "role": "leaf"},
  {"goal": "Оценить эргономику и нагрузку", "context": SOUL_HEALTH + data, "role": "leaf"},
])
```
