# GEO под ChatGPT — собственный робот и карточка в 200 символов (2026)
Источник: Habr, статья «ChatGPT не гуглит. У него свой поисковый робот, и с вашего сайта он берёт ровно 200 символов».
Автор: gottivartanian. База: ~1,9 млн источников ChatGPT (фев–июль 2026, браузерный + API каналы).
**См. также:** [[geo-yandex-alisa-2026]] — контраст: Алиса привязана к топ-10 Яндекса, ChatGPT к своему индексу.

## Главный вывод
ChatGPT НЕ ходит в Bing и НЕ гуглит. У него **собственный поисковый робот** (внутреннее имя `labrador`)
со своим индексом — даёт **97% всех источников**. Между вашим сайтом и ответом стоит посредник:
**карточка из ~200 символов** (заголовок + описание). Модель решает «годитесь ли вы» ИМЕННО по карточке,
страницу целиком в момент ответа не читает.

## Анатомия карточки labrador (собственный робот)
- Описание **ровно ~200 знаков** (99,9% — 195–205 знаков), обрывается многоточием на полуслове.
- **61% описаний начинаются с текста В ВЕРХНЕМ РЕГИСТРЕ** — это H1 страницы, снятый прямо с неё.
- Заголовок НЕ режется (как в поисковиках на 60–70 знаках): треть длиннее 75 знаков, рекорд — 1124 знака.
- Знает **дату публикации у 56%** страниц → хранит полноценную карточку, не только ссылку.
- Охват: **12 035 разных сайтов** (в т.ч. мелкие региональные, отраслевые — их нет в покупной выдаче).

## Покупная выдача (3% карточек, НЕ собственный робот)
Конвейеры `bright` / `oxylabs` / `serp` — перепроданные результаты внешних поисковиков по API.
Признаки: описание ~155 знаков, заголовок обрезан на 70, даты нет, 23% начинаются с «Dec 10, 2025 … Read more».
Доля по площадкам, которые блокируют чужих роботов:
Instagram **100%**, Pinterest **100%**, YouTube **88%**, LinkedIn **74%**, Reddit **43%**.
→ Собственный робот туда не проходит, данные докупаются. Ваш сайт (если открыт для краулера) попадёт в labrador бесплатно.

## Это НЕ Bing (доказательство из логов)
Два потока (собственный робот vs покупная выдача) **не смешиваются**: из 2500 ответов 2343 целиком на
собственном роботе, 71 целиком на покупной, ни одного со смешанными. Разные сайты (12k vs 318 доменов,
общих всего 175). Переключение канала целиком на ответ, не «добрали у поисковика».

## Что делать (GEO под ChatGPT)
1. **H1 критичен** — он попадает в начало карточки капсом. Чёткий, содержательный H1 с ключевыми словами.
2. **Первые ~200 символов страницы** = снапшот, по которому модель решает. Пиши суть сразу, без воды в начале.
3. **Дата публикации/обновления** видна роботу у половины страниц — держи актуальной, структурируй (schema/метаданные).
4. **Свой открытый сайт > только соцсети.** Instagram/Pinterest/YT/LinkedIn/Reddit ChatGPT докупает и видит хуже
   (обрезанные заголовки, без дат). Для B2B/экспертного GEO — база на собственном домене.
5. Длина заголовка не ограничена жёстко (в отличие от SEO под Google) — но содержательность важнее размера.
