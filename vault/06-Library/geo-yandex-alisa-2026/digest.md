# GEO под Яндекс/Алису AI — что работает (лето 2026)
Источник: Habr, Игорь Новиков (ig_novvv), 15 лет маркетинга, GEO/нейропоиск.
Замеры автора: 455 ответов Алисы AI, 2976 ссылок.

## Механика
Алиса AI (блок сверху в поиске Яндекса) НЕ использует свой индекс.
План ответа → запрос в ОРГАНИЧЕСКУЮ выдачу Яндекса → берёт страницы оттуда.
**Следствие: попасть в ответ = быть в топ-10 органики Яндекса.**

## Ключевые цифры
- Источники даёт в 99% ответов (ChatGPT — 70%, остальные — редко). Вход реален.
- Кол-во ссылок блоками: **5 = 65%**, 10 = 25%. Между ними — пусто. Фиксированные блоки выдачи.
- Повторяемость списка при 3× повторе вопроса: **67%** (ChatGPT — 32%).
  → Видимость в Алисе как позиция в поиске: попал в пятёрку — стабильно там.
- Топ-площадки цитирования: vc.ru (202), Дзен (124), Sostav (101), Habr (66), DTF (50) = 22% всех ссылок.
- Возраст домена и авторитет **почти не работают**. Работает ТЕКСТ конкретной страницы.

## Что делать
1. Целься в **информационные** запросы («как выбрать», «чем отличается», «что учесть»), не коммерческие.
   Страница услуги по ним не ранжируется → попадёт чужая статья. → Инфо-раздел на своём домене.
2. **Слова вопроса — в начало заголовка** страницы (отбор по тексту, не по репутации).
3. Чистый URL без параметров, вменяемая структура H2/списков.
4. Топ-10 органики лучше топ-20; после 5-й позиции шансы резко падают.
5. Замеры: фиксированный набор формулировок + повтор через пару недель (гонять 10× бессмысленно).

## Готча (не путать с западом)
У ChatGPT/Perplexity/Claude в ответ попадают страницы вне топ-10 Google, видимость — «лотерея».
У Алисы — жёстко привязано к топ-10 Яндекса. **Для GEO под РФ — отдельная стратегия, не копия западной.**

## Ограничения
Ниши — услуги для бизнеса; на товарных/медицинских может отличаться. Данные лето 2026, механика меняется.
