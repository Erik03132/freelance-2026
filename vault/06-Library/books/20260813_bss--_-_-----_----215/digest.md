# 20260813_BSS перевела _Речевую аналитику_ на рельсы автономных ИИ-агентов_ вышел новый релиз 2.15

## Суть (2-3 предложения)
Релиз 2.15 превращает «Речевую аналитику» из реактивного инструмента в проактивного автономного ИИ‑агента, который по расписанию анализирует записи и рассылает инсайты. Внедрена технология RAG для семантического контроля качества, улучшены модули оценки и проведён UX/UI‑рефакторинг, включая многоуровневую оценку Агента‑Тренера.

## Ключевые идеи
1. Переход от реактивного инструмента к проактивному автономному агенту с расписанным анализом и автоматической рассылкой инсайтов.  
2. Интеграция RAG (Retrieval‑Augmented Generation) в автоматические оценочные карты для точного семантического контроля качества на основе внутренних баз знаний.  
3. Расширение модулей контроля качества: гибкий семплинг, виджет «Дерево маркеров», отчёт «Распределение оценок» и справочники обратной связи.  
4. Улучшение Агента‑Тренера: многоуровневая оценка, языковая настройка, объяснение результатов, новый дашборд ученика и комплексный UX/UI‑рефакторинг.

## Паттерны/фреймворки
- **RAG (Retrieval‑Augmented Generation)** — сочетает поиск в корпоративных знаниях с генеративной моделью для точного семантического анализа без сложной интеграции.  
- **Автономный ИИ‑агент** — система, действующая по заранее заданному расписанию, инициативирующая анализ и доставку инсайтов без прямого пользовательского запроса.  
- **Многоуровневая оценка** — hierarchical scoring, включающий критические цели, которые могут мгновенно останавливать симуляцию и предоставлять детальное обоснование результатов.  
- **Компонентный UX/UI‑рефакторинг** — внедрение переиспользуемых UI‑компонентов с адаптивной фильтрацией и визуализацией для повышения юзабилити и скорости работы с данными.

## Применимо к нам
- Использовать автономный агент для регулярного анализа звонков и чатов наших AI‑агентов, отправляя инсайты в Slack/email без ручного триггера.  
- Внедрить RAG‑based оценку качества ответов, подключая внутреннюю базу знаний (FAQ, policy) для семантического контроля и автоматического генерирования оценочных карт.  
- Применить гибкий семплинг и виджет «Дерево маркеров» в нашей системе evals для быстрого выявления проблемных паттернов в диалогах.  
- Интегрировать многоуровневую оценку в пайплайн обучения агентов, позволяя немедленно останавливать обучение при критических ошибках и получать объяснения.  
- Воспользоваться компонентным UX/UI‑рефакторингом для построения адаптивных дашбордов мониторинга агентов (транскрибация, метрики, конструктор отчётов).

## Оценка ценности
8/10 — релиз предоставляет практические механизмы (автономный агент, RAG, улучшенные evals) которые напрямую повышают автоматизацию контроля качества и обучения наших AI‑агентов, хотя требует интеграционных усилий и адаптации под наши конкретные данные.
