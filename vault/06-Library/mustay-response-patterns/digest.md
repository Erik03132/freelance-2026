## 1. Концепция: Value-First Outreach (Ценность до контракта)
Mustay решает проблему баннерной слепоты рекрутеров и заказчиков, отправляя вместо банального резюме готовый **мини-консалтинг**:
1. Фиксация истинной потребности (Explicit Request).
2. Выявление 2 скрытых инженерных/бизнес-рисков (Hidden Risks: рост расходов на LLM, узкие горлышки API, галлюцинации).
3. Предложение зрелой архитектуры (Better Approach: FSM, Pydantic, гибридный RAG, очередь retry, Smart Fallback).
4. 2 квалификационных вопроса (Questions to Client).

## 3. Золотой банк формулировок и метрик (Proof Bank)

### Для AI / RAG / Агентов:
- *«Внедряю гибридный RAG (эмбеддинги + dense search + reranker) с замером метрик точности Hit@k и MRR»*.
- *«Проектирую cost-aware маршрутизацию LLM (Tier-0 / Tier-1 / Fallback) для снижения себестоимости и задержек каждого вызова»*.
- *«Фиксирую архитектуру в ADR и покрываю бизнес-логику eval-тестами»*.

### Для Telegram-ботов и CRM (Bitrix24 / Mango):
- *«Строю FSM-сценарии на aiogram с валидацией обязательных полей через Pydantic и Smart Fallback (бесшовный перевод на оператора)»*.
- *«Использую асинхронные очереди повторов (retry queue) для надежной передачи сделок в Bitrix24 REST API без потерь лидов при пиковых нагрузках»*.
- *«Упаковываю решение в Docker-контейнеры с автоперезапуском и мониторингом 24/7»*.
