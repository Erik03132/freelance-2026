Фреймворки для AI-агентов упрощают создание автономных систем — они предоставляют abstractions для планирования, использования инструментов, памяти и взаимодействия агентов между собой и с человеком.

## LangChain

LangChain — самый обширный фреймворк, с обширной экосистемой компонентов: цепочки, агенты, инструменты, мемори, векторные интеграции. Подходит для задач, где нужно быстро собрать прототип с доступом к большому количеству внешних сервисов и источников данных.

Плюсы: широкая экосистема, много интеграций, отличная документация, активное сообщество. Минусы: сложность для простых задач, в сложных сценариях приходится углубляться в детали.

## CrewAI

CrewAI — фреймворк для мульти-агентных систем, где каждый агент имеет роль, цели и набор инструментов. Агенты работают в crew и сотрудничают для решения сложной задачи.

Плюсы: простой подход к multi-agent, role-based архитектура. Минусы: меньше интеграций, чем LangChain, меньше низкоуровневой гибкости.

## AutoGen

AutoGen — фреймворк от Microsoft для диалогов между агентами и человека. Агенты могут общаться между собой в формате диалога, обсуждать решения, делегировать задачи.

Плюсы: гибкая модель диалога, good для research-сценариев. Минусы: сложнее для production, подходит не для всех бизнес-задач.

## DSPy

DSPy — фреймворк для программируемого оптимизирования промптов и signatures. Вместо ручного написания промптов DSPy позволяет декларировать сигнатуры и оптимизировать их автоматически на основе примеров.

Плюсы: программируемая оптимизация промптов, reproducibility, good для production-сценариев. Минусы: требует примеров для оптимизации, меньше готовых агентных abstractions.

## Как выбрать фреймворк

- Простой прототип с интеграциями — LangChain.
- Мульти-агентная система с ролями — CrewAI.
- Диалог между агентами — AutoGen.
- Стабильные промпты, оптимизация под данные — DSPy.
- Сложный production-сценарий — комбинация: DSPy для промптов + LangChain/CrewAI для orchestration.

В реальных проектах мы часто комбинируем несколько подходов: LangChain для доступа к инструментам и данным, DSPy для оптимизации ключевых промптов, кастомную логику для бизнес-процессов.
