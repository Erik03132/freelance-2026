# EXTERNAL_SERVICE_RULES.md

> Правила работы агентов с **внешними сервисами** (Ozon Seller, WB Seller, Mango Office, Bitrix24, Т-Банк, ЮKassa, и т.д.)
> Применимо ко всем агентам: Шерлок, Кулибин, Ботман, Angela.

## Главный принцип

**Свой аккаунт — твоя ответственность. Агент = инструмент, не решение.**

## Чтение (автономно)

- Агент **может** читать данные из сервиса через официальный API, реверс-curl или UI-автоматизацию **без явного подтверждения** на каждый запрос.
- Кэшировать, индексировать, искать по прочитанному — можно.
- Логировать: что читал, откуда, когда.

## Запись (ТОЛЬКО через подтверждение)

Любое действие, которое меняет данные в чужом сервисе:

- Создание/удаление/изменение записи (заказ, лид, комментарий, статус)
- Отправка сообщения/рассылки
- Изменение настроек аккаунта
- Покупка/бронирование/оплата
- Публикация контента
- Любые операции, которые нельзя отменить кнопкой «Undo»

**Правило:** перед записью показать Игорю **что изменится** (diff, JSON-тело запроса, итоговое сообщение). Получить явное «да» — только тогда выполнять.

**Формат подтверждения:**
```
ДЕЙСТВИЕ: [кратко, 1 строка]
СЕРВИС:   [имя]
ЧТО ИЗМЕНИТСЯ:
  - поле1: было X → станет Y
  - поле2: ...
ОБРАТИМО: да/нет/частично
ПОДТВЕРЖДАЕШЬ? [да/нет]
```

## Чего НЕ делать без отдельного одобрения

- Массовые операции (>10 записей за раз)
- Операции с деньгами (любая сумма)
- Действия с чужими аккаунтами (только свой)
- Обход CAPTCHA (если сервис показывает — стоп)
- Действия в обход ToS сервиса (даже если технически работает)

## Юридические чек-листы (перед первым использованием сервиса)

- [ ] Прочитан ToS сервиса, понятны ограничения
- [ ] Реверс-curl не нарушает 152-ФЗ / GDPR (какие данные отдаёт)
- [ ] Токены/секреты — в `.env`, **не** в коде, **не** в коммитах
- [ ] Логика записи — через диалог, не автоматом

## Если сервис прямо запрещает автоматизацию

Не делать. Даже если:
- Это твой аккаунт
- Другие люди делают и ничего
- Технически работает

ToS = контракт. Нарушение = риск бана аккаунта + потенциальные претензии.

## Безопасность находок

Если агент сделал реверс (F12 → Network → Copy as cURL):

- **Метод** (как делать) — публикуемо в `docs/integrations/<service>-method.md`
- **Endpoint'ы конкретного аккаунта** — НЕ публикуем. Держать в `docs/integrations/<service>-private.md` (в PRIVATE-ветке freelance-2026, не на публичном GitHub)
- **Токены/куки** — никогда в коде, только в `.env`

## Когда применять

Каждый раз, когда задача:
- Интеграция с маркетплейсом/банком/CRM/рассылкой
- Запуск бота в Telegram/WhatsApp/Max
- Выгрузка данных из чужого кабинета
- Автоматизация рутины в SaaS

По умолчанию — **чтение автономно, запись через подтверждение**.
