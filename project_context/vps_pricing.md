# VPS & S3 Pricing — TimeWeb (pay-per-use JSON rates) (2026-09-01)

## Источник
- **TimeWeb VPS** — https://timeweb.com/ru/services/vps/ (Next.js RSC payload, 2026-09-01)
- **TimeWeb Cloud additional services** — https://timeweb.cloud/prices/ (2026-09-01)
- **Selectel VPS** — недоступен (timeout)
- **S3 prices** — web_search недоступен; публичные типовые цены

## ⚠️ Расшифровка JSON-цен

`discount_value` в JSON — это **цена в копейках за сутки** в режиме **pay-per-use** (почасовая оплата, без фиксированной месячной оплаты).

| Поле | Что значит |
|---|---|
| `discount_value` | Цена **в копейках/сутки** (pay-per-use) |
| `discount_type` | `"fixed_price"` — фиксированная цена (не скидка!) |
| `default_bandwidth` | Включённый интернет, Мбит/с |
| `cpu_frequency` | Частота CPU, ГГц |
| `vds_node_configuration_name` | Узел в дата-центре |

**Месяц = 30 дней.**

## Примечания

1. **pay-per-use** = оплата только за время работы (почасово). Если сервер выключен — не платишь.
2. **Страничные цены** (900₽/мес для Cloud-40) включают 10% скидку за годовую оплату и являются фиксированными.
3. **JSON `discount_value`** — цена в копейках/сутки для pay-per-use режима.
4. Москва (ru-3) High MSK тарифы с 5.5 ГГц — самые производительные процессоры в TimeWeb.
5. Нидерланды (nl-1) даёт 1000 Мбит/с уже на стартовых тарифах, Германия — только 200 Мбит/с.
6. **Cloud NSK** в Новосибирске — более дешёлые тарифы, но только 100 Мбит/с.
7. Казахстан (kz-1) — в 4x дороже из-за международного трафика и локации.
8. Selectel недоступен (timeout через прокси) — требуется отдельный запрос.
9. S3 цены TimeWeb — типовые, проверить в панели управления.
