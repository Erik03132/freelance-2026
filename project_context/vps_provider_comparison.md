## Рекомендации

### Текущий статус — НЕ менять
- TimeWeb работает, всё живое на `217.149.23.113`
- Тариф Cloud-50 узкий по RAM (3.8 ГБ, свободно ~175 MiB) — Bottleneck при росте
- **TimeWeb Cloud-80 (540₽/мес)** даёт 4 CPU / 8 ГБ / 80 ГБ / 1 Гбит — достаточно для текущих задач, минимальный шаг

### Если нужна миграция — Beget предпочтительнее
Преимущества Beget для нашего стека:
1. **Qdrant из marketplace** — не поднимать через Docker вручную
2. **Hermes в marketplace** — предустановленный образ (миграция всё равно потребует ручной настройки, но базовый образ есть)
3. **S3-хранилище** — заменит Timeweb S3 для `igor-shared` (S3-совместимый API, `rclone` работает аналогично)
4. **NVMe + 1 Гбит/с** — лучше дисковой подсистемы, чем у TimeWeb Cloud-50
5. **Бэкапы включены** — дополнительно не нужно настраивать snapshots
6. **Посуточная тарификация** — гибкость (для нас 24/7 не актуально, но удобно при перебоях)

### Компромисс по цене
- Beget 4 ядра / 12 ГБ / 150 ГБ (~3 600₽/мес) — примерно в 3 раза дороже текущего TimeWeb Cloud-50, но даёт 3× ресурсов и все фичи (Qdrant + S3 + Hermes marketplace)
- По price/performance **выгоднее**, чем поднимать TimeWeb Cloud-160 (1 290₽/мес) или подтягивать узкий Cloud-50
- Selectel — отпадает: нет Qdrant, нет Hermes marketplace, страница недоступна

## Что проверить перед миграцией на Beget (research-чеклист)

- [ ] **marketplace Hermes** — что именно предустановлено (скрейп страницы `beget.com/ru/cloud/marketplace/hermes` заблокирован, нужна картинка/описание из панели)
- [ ] **Beget S3 + rclone** — работает ли напрямую или нужен промежуточный переход (тест на пустом бакете)
- [ ] **Qdrant в marketplace** — версия, совместимость с планами по векторизации знаний, API-ключ
- [ ] **api-cp.beget.com из VPS** — доступность для API-управления после деплоя
- [ ] **Миграция данных** — rsync профилей `/root/.hermes`, S3-бакет `igor-shared`, pm2-дамп, systemd-юниты
- [ ] **Туннель Mac↔Beget** — пересборка autossh (новый IP, возможно другой порт)
- [ ] **Пинг СПб→Мак** — убедиться, что маршрут из СПб приемлем (сейчас пинг TimeWeb Москва ~20–40 мс)
- [ ] **US-прокі** — остаётся 172.120.21.141:64468 (для foreign API, не привязан к провайдеру VPS)
