# ADR-001: Генеративный пайплайн схемы пазла (вместо трассировки референса)

**Статус:** принято (2026-08-18)
**Контекст:** задача Рембрандта — сгенерировать схему лазерного реза «Танцы в
облаках» (450 деталей, 310×430 мм) по ТЗ, имея два эталона .ai (PDF 1.5).

## Проблема

Нужно получить рабочий векторный файл, удовлетворяющий жёстким производственным
требованиям: 450 деталей ≤30 мм, зазор ≥3 мм, 0.2 pt, чёрные контуры + голубые
прорисовки. Альтернативы: (а) трассировать растровые референсы из ТЗ, (б) брать
за основу структуру эталона, (в) генерировать программно.

## Решение

Выбрана **детерминированная программная генерация** (`generate.py`):

1. **Пэчворк-сетка**: поле 310×430 мм → сетка 18×25 = 450 ячеек; грани ячеек —
   синусоидально-волнистые (общие для соседей); каждая ячейка стягивается
   `buffer(−1.5 мм)` → гарантированный зазор 3 мм между всеми соседями.
2. **Прорисовки**: библиотека примитивов (волны/ели/дома/коловрат/облака/птицы/
   танцоры/ленты), назначаются по вертикальной зоне centroid детали.
3. **Экспорт**: один SVG, `stroke-width="0.2"`, чёрные замкнутые контуры деталей,
   голубые линии прорисовок, единицы mm.

## Почему не трассировка референса

- Референсы из ТЗ (jpeg/png ИИ-варианты) — цветные растры без гарантии чистоты
  контуров; трассировка даёт «грязные» пути, недетерминированный результат и риск
  пересечений/незамкнутости — критично для реза.
- Рабочая модель без vision не может контролировать художественное качество трейса.

## Последствия

+ Все производственные требования проверяемы автоматически (verify.py, eval suite).
+ Полная воспроизводимость: `--seed` → одинаковый SVG.
+ Независимость от внешних сервисов (SVGMaker MCP, StarVector не нужны).
− Художественное качество прорисовок ограничено библиотекой примитивов
  (для премиум-релиза — второй проход дизайнера).
− Форма деталей регулярна (сетка), «орнаментальная фигурность» краёв ограничена
  амплитудой волн — сохраняется строгий зазор.

## Компромиссы

- Волнистость граней ≤0.8 мм амплитудой — при buffer −1.5 мм не создаёт
  самопересечений и сохраняет ровный зазор.
- Детали медианно ~16 мм (меньше лимита 30 мм) — пазл лёгкий, надёжный для резки.
