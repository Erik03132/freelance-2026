# Brief для дизайнера — художественный второй проход (PZL-4)

Схема пазла **«Танцы в облаках»** для лазерной резки (клиент «Доброе Время»).
Рабочие файлы рядом: `Танцы в облаках_310 x 430_450 дет.svg` (+ `.pdf`, `.png`).

## Что уже сделано пайплайном (НЕ трогать)

- **450 деталей**, поле **310×430 мм**, вертикальная композиция.
- **Чёрные замкнутые контуры** = линии реза; между деталями гарантированный **зазор 3 мм**, каждая деталь **≤30 мм** по большей стороне.
- Толщина всех линий **0.2 pt**.
- **Внешняя рамка** — чёрный прямоугольник по периметру.

Эти ограничения — производственные (лазерный центр сверяет по ним рез). Их менять нельзя — меняется только слой прорисовки.

## Что нужно от дизайнера (голубой слой прорисовок)

Сейчас прорисовки — базовые генеративные примитивы. Нужно сделать их «премиально-сюжетными» по ТЗ клиента:

1. **Нижняя зона (0–30% высоты) — земля/деревня.** Водные ряби и волны Белого моря, ёлки, деревянные дома, церковь с куполом, заборы, тропинки, снежинки, лодочка; «мужик в ушанке с собакой» (акцент уже есть).
2. **Средняя зона (30–56%) — солнце с коловратом.** Коловрат за линией леса (видна верхняя половина), лучи, пламевидные завитки, ленты, уходящие вверх.
3. **Верхняя зона (56–100%) — небесный хоровод.** 8–12 танцоров в народных костюмах по спирали (девушки: сарафаны, кокошники, косы, бусы; парни: рубахи, шапки, сапоги, поднятые руки), облака-завитки вдоль спирали, птицы, S-ленты, орнаменты; связь фигур — руки, взгляды, ленты.

Отсылки к сказу Писахова «Девки в небе пляшут» (мелко, по желанию): сапог, пристукивающий о землю; гармонь; кружка; птица «в пляске».

## Правила правки (важно)

- **Только голубой цвет** `rgb(16.078186%, 67.059326%, 88.627625%)`, толщина **0.2 pt**, `fill="none"`.
- Линии прорисовки **не должны пересекать чёрные контуры** своих деталей (и тем более соседних).
- Чёрный слой не редактировать.

## Формат сдачи

SVG по той же структуре (можно редактировать прямо этот файл и вернуть .svg). Результат положить в `exchange/designer/`.
