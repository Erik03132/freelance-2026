# ai-bus — «Автобус + алгоритм выживания»

Цифровой предрейсовый инструктаж для автотранспортных предприятий: ежедневный
3–5-минутный брифинг в смартфоне водителя (обстановка дня → короткое видео →
ситуационные задачи → мини-тест → фото-подтверждение → автозапись в журнал).
Цель — превратить формальный инструктаж в реальную подготовку водителя к
типовым ЧС: БПЛА, теракты/диверсии, ДТП, агрессивные пассажиры.

## Статус

Пилот. Целевой контур: 1 автотранспортное предприятие, 100 водителей, 8 недель.
Канал доставки: VK Mini App (фолбэк — Telegram Mini App).

## Ключевые ограничения (зафиксированы в ADR)

1. Система **не заменяет** устный очный инструктаж по транспортной безопасности
   (приказ Минтранса № 167 от 06.05.2024) — готовит к нему и фиксирует
   предрейсовый инструктаж по БДД (приказ Минтранса № 145).
2. Журнал в MVP — электронная форма на ПО с цифровой фиксацией (timestamp, sha256,
   медиа); усиление ЭП по 63-ФЗ — после пилота.
3. Персональные данные (фото, результаты тестов): согласие водителя, хранение
   в РФ, минимальный retention — 152-ФЗ.
