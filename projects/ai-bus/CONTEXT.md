# CONTEXT.md — доменные термины ai-bus

| Термин | Значение |
|--------|----------|
| Предрейсовый инструктаж | Обязательный инструктаж перед отправлением в рейс (дороги, погода, опасные участки, ЧС). Регламент — приказ Минтранса № 145 от 30.04.2021 |
| Специальный инструктаж | Инструктаж при необходимости немедленно довести информацию (вкл. угрозы терактов) — там же |
| Журнал учёта инструктажей | Документ с датой, видом инструктажа, ФИО проводившего и водителей, подписями. № 145 допускает электронный вид на ПО |
| Персонал субъекта ТБ | Водители, отнесённые к персоналу субъекта транспортной безопасности; для них действует приказ Минтранса № 167 (устный очный инструктаж + устное тестирование) |
| АУН | Акт незаконного вмешательства (16-ФЗ «О транспортной безопасности») |
| Допуск на линию | Разрешение диспетчера на выезд; в проекте — статус после успешного прохождения брифинга |
| Сводка дня | Утренняя информация диспетчера/системы: погода, дорожная обстановка, угрозы, перекрытия |
| Брифинг | Короткий (3–5 мин) блок: видео 1–2 мин + ситуационные задачи по 4 темам выживания |
| Анти-фрод | Механизмы против «формального прохождения»: перемешивание вопросов, мин. время теста, фото-подтверждение |
| ЭПЛ | Электронный путевой лист (формат ФНС ЕД-7-26/116@) — интеграция фазы 2, вне пилота |
| ЭП | Усиленная/простая электронная подпись (63-ФЗ) — фаза 2, вне пилота |
| VK Mini App | Приложение внутри ВКонтакте (VK Bridge API: камера, гео) — основной канал доставки |
