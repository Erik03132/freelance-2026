# ADR-002: Система не заменяет устный очный инструктаж по транспортной безопасности

- **Дата:** 2026-10-10
- **Статус:** принято
- **Контекст:** Приказ Минтранса России от 06.05.2024 № 167 требует для персонала
  ТС (отнесённого к персоналу субъекта ТБ) инструктаж по транспортной
  безопасности **только в устной форме, очно, до начала перевозки**, завершаемый
  устным тестированием. Приказ Минтранса № 145 (предрейсовый инструктаж) допускает
  электронный журнал. Соблазн «оцифровать весь инструктаж» конфликтует с № 167.
- **Решение:** Продукт занимает чёткую позицию:
  1. Цифровая часть = предрейсовый инструктаж по БДД (№ 145) + темы выживания
     (БПЛА/АУН/ДТП/пассажиры) как содержательная надстройка.
  2. Инструктаж по ТБ (№ 167) остаётся устным и очным — система готовит к нему
     водителя (материалы, тренировочные вопросы) и фиксирует прохождение
     предрейсовой части, но не заменяет устную проверку ответственного за ТБ.
  3. В UI диспетчера эти два трека разведены: «брифинг пройден» ≠ «инструктаж по
     ТБ проведён».
- **Последствия:** Нет конфликта с № 167 на пилоте; ценность для СБ не
  дискредитируется; при желании усилить — отдельный ADR с заключением юриста.
- **Связано:** ADR-001 (скрипинг), ADR-003 (журнал). Требуется ревью юристом
  предприятия перед подписанием пилота.
