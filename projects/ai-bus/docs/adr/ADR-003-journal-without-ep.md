# ADR-003: Журнал в MVP — цифровая фиксация (timestamp + sha256 + медиа) без ЭП

- **Дата:** 2026-10-10
- **Статус:** принято (пересмотр после пилота)
- **Контекст:** Приказ Минтранса № 145 допускает электронный журнал на ПО с
  заверением ЭП (63-ФЗ). Но внедрение УКЭП/НЭП для 100 водителей — стоимость,
  токены/сертификаты, обучение — на старте избыточны. Нужен промежуточный
  уровень доказательности.
- **Решение:** В MVP каждая запись журнала несёт: server-side timestamp (UTC),
  sha256 хеш контента сессии (вид теста, ответы, id медиа), ссылки на медиа
  (фото-подтверждение), device fingerprint. Выгрузка журнала (PDF/CSV) —
  кнопкой. ЭП — фаза 2 после пилота (AIB-050), если заказчик/проверки потребуют
  усиленной формы.
- **Последствия:** Журнал пригоден для внутреннего контроля и для сверки
  «кто/когда/что прошёл»; на проверках может быть признан ведением журнала в
  электронном виде — вопрос согласования с юристом предприятия. Не является
  ЭП-заверенной формой до внедрения 63-ФЗ.
- **Связано:** ADR-001, ADR-002.
