# Сравнение хостингов: Beget vs Timeweb (текущий) vs Selectel

> Дата: 2026-09-01. Цены актуальны на момент проверки (живые данные с сайтов).
> Стек Levitan: LiveKit-SIP голосовой агент + STT/TTS + LLM/OmniRoute + S3 + Qdrant (RAG/FAQ) + DBaaS.

---

## 1. Что реально нужно Levitan (стек)

Из `chp.md` / `active_tasks.md`:

| Компонент | Текущее решение | Требование к хостеру |
|-----------|----------------|----------------------|
| **VPS** | Timeweb 1 vCPU/2GB/30GB NVMe | CPU — узкое место (load=1.0 при 100%). Нужен **2-4 vCPU / 4GB RAM**. Стабильная сеть (текущая: пинг 670-800мс, SSH 95% отказов) |
| **SIP** | livekit-sip + REGISTER на Mango | Порты 5060, RTP 16384-32768; стабильная регистрация 24/7 |
| **LLM** | YandexGPT-lite (основ.), OmniRoute fallback | OmniRoute — Node.js, жрёт RAM (npm 644MB при 1GB) |
| **STT** | faster-whisper (локально) | Грузит CPU — чем больше ядер, тем лучше |
| **TTS** | Yandex SpeechKit, edge-tts | Облачное, CPU мало |
| **S3** | Записи звонков | 30-100 ГБ, дешёвый, совместимость с AWS S3 API |
| **Векторная БД** | Qdrant (план RAG/FAQ) | Готовый образ или ручная установка |
| **DBaaS** | PostgreSQL / Redis (диспатч) | Postgres, нотификации |


## 6. Hermes Agent (готовый образ) и AI-инфраструктура

| Провайдер | Hermes образ | Полнота образа | LLM-возможности |
|-----------|--------------|----------------|------------------|
| **Beget** | ✅ маркетплейс `latest` | Базовый (Hermes) | ❌ Своего LLM-шлюза нет — только внешние API |
| **Timeweb** | ✅ маркетплейс AI (`Hermes`) | Образ + интеграция с их AI Gateway | ✅ **AI Gateway** (`api.timeweb.ai/v1`): GPT, Claude, Gemini, DeepSeek, Grok; 1-й агент бесплатно до 31.12.2026 |
| **Selectel** | ✅ `Hermes Agent Virtual Machine` | **Самый полный**: Hermes + Docker + Docker Compose + GPU-драйверы + Web-GUI | ✅ **ИИ-роутер + Foundation Models Catalog** (корпоративный уровень), GPU-опция |

> **Ключевой нюанс:** Hermes — это **текстовый/действенный** агент (код, админка, интеграции), НЕ голосовой SIP-агент. Для нашего LiveKit-SIP-стека образ Hermes живёт рядом, но LiveKit-агент в любом случае ставим руками (как на текущем Timeweb). Hermes закрывает текстовую автоматизацию (Telegram-бот, мониторинг, отчёты), а не голосовой обзвон.

## 9. Рекомендация

**Оптимальный кандидат для миграции — Beget**, если:
1. Нужны **готовые S3 + Qdrant** (закрываю записи звонков и RAG/FAQ-кэш в один клик).
2. Хочется **дешевле** в малых конфигурациях.
3. Готовы проверить **стабильность сети** (у Timeweb она нас подвела).

**Оставить на Timeweb**, если:
1. Ценен **AI Gateway** (свой LLM-шлюз с моделями) — у Beget такого нет, LLM остаётся на внешних API.
2. Не хочется раскатывать заново (миграция LiveKit/SIP = время и риск).

**Selectel** — только если нужен корпоративный SLA + возможность локальных LLM на **GPU** (дорого для текущего масштаба).

### План проверки перед решением (по анти-авторитету, ADR-013)
1. Завести тестовый VPS у **Beget** (2 vCPU/4 ГБ, ~1 140 ₽/мес).
2. Проверить **сеть**: стабильность пинга, SSH, SIP-регистрацию на Mango, живую REGISTER.
3. Проверить **TTFT/латентность**: YandexGPT-lite через VPS ↔ интернет.
4. Поднять **Qdrant** (маркетплейс) и прогнать RAG/FAQ-тест.
5. Если сеть стабильна и латентность ок → **ADR-004: миграция на Beget**, иначе остаться.
