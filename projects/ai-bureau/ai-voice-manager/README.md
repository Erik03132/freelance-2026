# AI Voice Manager (AVM) — AI-голосовой менеджер для локального бизнеса

**Название по-русски:** AI-голосовой менеджер для локального бизнеса

**Статус:** концепция / pre-product. Голосовой агент ещё не стабилен (см. зависимости → Levitan).

## Суть продукта

Продаём локальному бизнесу «сотрудника, который не пропускает звонки и сам доводит клиента до записи»:

- Приём входящих звонков (голосовой агент на LLM, не скрипт по кнопкам)
- Общение в WhatsApp/Telegram (бот)
- Запись клиента в CRM (Bitrix24)
- Мгновенный обзвон новых лидов (сайт/Авито → звонок за 30 сек)
- Работает 24/7, без выходных

Модель дохода: **рекуррентная подписка** (тарифы 7-60К₽/мес), маржа ~70%.
