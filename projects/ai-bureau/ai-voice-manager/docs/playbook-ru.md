# Локальный playbook для РФ: AI Voice Manager (AVM)

Адаптация методики из видео «Make $10K/Month with GoHighLevel By Copying These Winning Agencies»
(Hamza Automates, 11.08.2026, https://www.youtube.com/watch?v=IQ8ZJGq0clk) под российский рынок и стек Levitan + Mango + Bitrix24.

Ключевая развилка: GoHighLevel в РФ не работает (оплата в $, Stripe, нет RU-интерфейса).
Локальный аналог «всё в одном» = связка Bitrix24 + Mango + голосовой агент Levitan.
Паттерн funnel-hacking (копировать доказанных победителей) переносится полностью.

---

## 1. Аналог «Level Up Awards» для РФ — где брать «победителей»

| Что в видео (GHL) | Локальный аналог | Как использовать |
|---|---|---|
| Level Up Awards (Gold/Platinum/Diamond) | Каталог партнёров Bitrix24 (золото/платина по уровням) и amoCRM Solution Providers | Та же метафора: «золотые» интеграторы = 10К₽+/мес |
| Реестр победителей | Кейсы на VC.ru / Habr: «внедрили amoCRM + обзвон → N сделок» | Funnel-hack офферов агентств: прайс, ниша, воронка |
| Funnel hacking (подписка на триал) | Купить 1 мес услуг конкурента / заказать их демо | Пройти их воронку изнутри |
| Facebook Ads Library | Яндекс Аудит / VK Реклама — смотреть офферы конкурентов | Актуально, но не критично |
| Cold email победителям | LinkedIn/VC-профили владельцев интеграторов | Звонок: «видел кейс с обзвоном, 15 минут?» |

Практический источник №1: собственный кейс обзвона бройлеров (Angela/Vezemcip) — готовый case study
«AI-обзвон = подтверждение заказов, цены, лиды».

## 2. Ниши для РФ (где боль = телефон)

| Ниша | Боль | Оффер |
|---|---|---|
| Медклиники / стоматологии | Пропущенные звонки = потерянная запись | AI-администратор: приём звонков + запись в CRM |
| Автосервисы / шиномонтаж | «Когда приехать», перезвоны | AI-секретарь + запись + напоминание |
| E-commerce / доставка | Подтверждение заказов, «куда доставка» | Обзвон заказов (работающий кейс) |
| Фитнес / единоборства | Пробные тренировки, отработка входящих | AI + CRM + отписки |
| Строительство / ремонт | Лиды с Авито тонут | Обзвон лидов за 5 мин + квалификация |
| Юристы / бухгалтеры | Квалификация входящих | AI-скринер «это клиент?» |
| HoReCa | Бронь столов | AI-бронь + календарь |

Правило из видео: одна и та же формула, разные ниши. Не распыляться — 1-2 ниши, 20 клиентов в нише.

## 3. Офферы и прайсы (₽, реалистичные для РФ)

| Тариф | Что входит | Разово | Подписка | С/с/мес |
|---|---|---|---|---|
| Старт | AI-секретарь (приём звонков/WhatsApp/Telegram) + запись в таблицу/CRM + отчёт | 15 000-25 000 ₽ | 7 000-12 000 ₽/мес | ~2-3К (Mango 3-15₽/мин, LLM 5-20₽/день, VPS) |
| Бизнес | Старт + CRM Bitrix24 + автообзвон лидов + напоминания | 30 000-60 000 ₽ | 15 000-30 000 ₽/мес | ~5-8К |
| Агентство | Всё + воронки, скрипты, дашборд, апселы | 100 000-200 000 ₽ | 40 000-60 000 ₽/мес | ~15-20К |

Юнит-экономика (тариф Бизнес, 20 000 ₽/мес):
- Себестоимость: ~6 000 ₽ → маржа 70%
- Цель 10К$/мес = ~900 000 ₽/мес → 30-45 клиентов
- Реалистично для РФ на старте: 10-15 клиентов = 150-300К₽/мес (полупассивный доход)

Ключевое из видео: цена оффера не в «сайте», а в «одном спасённом заказе в месяц».
Оффер = «вернём один потерянный звонок в день, и оффер окупится».

## 4. Воронка продаж (2 канала)

**A. Исходящий обзвон (сильное место — есть опыт):**
1. База: 2ГИС/Яндекс Карты → 100-200 бизнесов в нише
2. Проверка «нет чата/автоответчика» на сайте (искать бизнесы БЕЗ AI-обслуживания)
3. Скрипт: «Вы пропускаете звонки после 18:00? Есть робот, который записывает клиентов, пока вы спите. Могу показать на вашем номере за 10 минут»
4. Демо-конвейер: скрейп сайта клиента → KB → AI-агент → демо-звонок владельцу (10 сек настройки, WOW)
5. Цель: 10-20 демо → 3-5 закрытий

**B. Входящие:** лендинг-визитка + кейс на VC/Habr + Telegram.

## 5. Фулфилмент (готовый стек, на 90%)

| Компонент | Инструмент | Статус |
|---|---|---|
| Голосовой агент | Levitan (livekit-sip + Mango) | ⚠️ нестабилен — гейт продаж |
| TTS | Яндекс Realtime (~330мс, рублёвая оплата) | ✅ |
| CRM | Bitrix24 (вебхуки) | ✅ |
| Чат-боты | Telegram aiogram | ✅ |
| LLM | OmniRoute (DeepSeek) | ✅ |
| VPS | Timeweb ~1 775 ₽/мес | ✅ |

Онбординг клиента (шаблон): скрейп сайта/телефонии → KB за 1 час → тест агента → 5 контрольных звонков →
включение на живой номер → скрипт приветствия по нише. Фулфилмент 2-4 дня.

## 6. Метрики и риски

Метрики: доля ответов в обзвоне, конверсия в демо (10-20%), закрытие (25-30%), churn (цель <5%/мес),
«сэкономленные часы оператора» — метрика для отчёта клиенту.

Риски РФ (в видео нет — добавляем):
- 152-ФЗ: исходящий обзвон — только по базам с согласием или юрлицам; согласие в первом звонке
- Телеком-антиспам: агрессивный обзвон с одного номера → Mango режет. Диверсифицировать номера, тайминги
- Скепсис к роботам: честно позиционировать «это AI», качественный TTS
- Не строить на одном клиенте: 3-5 клиентов до масштабирования

---

## 7. Роадмап 60 дней

1. День 1-3: выбрать 2 ниши → собрать 100-200 контактов (2ГИС) → зафиксировать в CRM
2. День 3-7: демо-конвейер (скрейп → KB → AI-агент → демо-звонок) — достроить в Levitan
3. Неделя 2-3: исходящий обзвон (скрипт + согласия), 10-20 демо/нед
4. Месяц 1: 3-5 клиентов (тариф Бизнес) = 60-150К₽/мес, референсы
5. Месяц 2: 10 клиентов = 150-300К₽/мес, автоматизация онбординга, кейс на VC
