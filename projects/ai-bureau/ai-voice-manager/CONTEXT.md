# CONTEXT.md — AI Voice Manager (AVM)

Доменные термины проекта.

| Термин | Определение |
|--------|-------------|
| **AVM** | AI-голосовой менеджер — продукт для локального бизнеса (приём звонков + чаты + CRM) |
| **Голосовой агент** | LLM-агент, ведущий живой диалог по телефону (не IVR по кнопкам) |
| **IVR** | Автоответчик по кнопкам — НЕ то, что мы продаём |
| **Funnel hacking** | Reverse-engineering чужого оффера/воронки у доказанных победителей |
| **Рекуррентный доход** | Подписка клиента; ключевая метрика модели |
| **Демо-конвейер** | Скрейп сайта клиента → KB → AI-агент → демо-звонок владельцу за ~10 сек |
| **KB (knowledge base)** | База знаний агента по бизнесу клиента (цены, услуги, график) |
| **Гейт стабильности** | Условие «агент стабильно отвечает без немых звонков» — до него продукт НЕ продаём |
| **Локальный бизнес** | Клиника, автосервис, доставка, фитнес и т.п. — ЦА продукта |
| **Лид-тишина** | Пауза до 5с, когда LLM ещё думает — абонент вешает трубку (главный блокер качества) |
