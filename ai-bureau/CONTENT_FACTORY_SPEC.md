# Content Factory — Pipeline & Stack v2

---

## 🏗 Архитектура (User-Approved Pipeline)

```
Шекспир (генерация текста)
    │ 5 вариантов
    ▼
Ты в Telegram (апрув / правки)
    │ ✅
    ▼
Рембрандт + Leonardo.ai (генерация изображения)
    │ 2 варианта
    ▼
Ты в Telegram (выбор картинки)
    │ ✅
    ▼
Автопубликация веером:
    ├── Telegram (канал + бот)
    ├── VK (стена группы)
    └── Яндекс Дзен (RSS-лента)
```

---

## 👤 Роли

| Роль | Кто | Задача |
|------|-----|--------|
| **Копирайтер** | Шекспир (skill) | Пишет 5 вариантов текста |
| **Дизайнер** | Рембрандт (skill) | Генерирует 2 варианта изображения через Leonardo.ai |
| **Главред** | Ты | Выбирает текст + картинку |
| **Публикатор** | Python-скрипт | Постит готовое на все площадки |

## 📝 Процесс шаг за шагом

### Шаг 1: Шекспир генерирует 3 варианта
```bash
# Запрос к Шекспиру
/skill agents/shakespeare
"Напиши 3 варианта поста для Telegram на тему: {тема}.
Тон: экспертный, живой. 
Длина: 300-500 знаков.
Ссылка на сайт: естественно встроенная.
Формат: полезный контент, не реклама."
```

**Что важно:**
- Все 3 варианта — на одну тему, но с разными заходами
- В каждом — скрытая ссылка на сайт
- Разная длина, разный тон

### Шаг 2: Ты апрувишь кнопками в Telegram
Шекспир присылает 3 варианта в личку.

```
📝 3 варианта поста на тему "Голосовой агент"

─── Вариант 1 ───
{текст}

─── Вариант 2 ───  
{текст}

─── Вариант 3 ───
{текст}

───
Выбери вариант или напиши правку:
```

**Кнопки:** `[Вариант 1 ✅]` `[Вариант 2 ✅]` `[Вариант 3 ✅]` `[Переписать ✏️]`

Тыкаешь кнопку → пост уходит на генерацию картинки.
Если ни один не подошёл — «Переписать» → Шекспир делает ещё 3.

### Шаг 3: Рембрандт делает 2 картинки + кнопки
```bash
/skill agents/rembrandt  
"Картинка для поста: {утверждённый текст}.
Стиль: технологичный, minimal, тёмная тема.
Формат: 1200x630 (OG-стандарт).
Канал: Leonardo.ai Phoenix."
```

Рембрандт присылает 2 варианта в Telegram.

**Кнопки:** `[Вариант 1 ✅]` `[Вариант 2 ✅]`

Выбираешь → публикация веером.

### Шаг 4: Автопубликация
```bash
python3 publish.py \
  --text "утверждённый текст" \
  --image "утверждённое изображение.png" \
  --platforms tg,vk,dzen
```

Скрипт делает:
1. Telegram: `sendPhoto` с текстом и картинкой → в канал `@ai_bureau`
2. VK: `wall.post` с картинкой и текстом → на стену группы
3. Яндекс Дзен: сохраняет статью в `src/content/blog/` → при следующем `astro build` попадает в RSS → Дзен подхватывает

## 📁 Структура

```
ai-bureau/content-factory/
├── drafts/                    # Черновики от Шекспира
│   └── {date}-{topic}/
│       ├── variants/          # 5 вариантов текста
│       │   ├── 01.md
│       │   └── ...
│       └── images/            # 2 варианта картинки
│           ├── rembrandt-01.png
│           └── rembrandt-02.png
├── approved/                  # Утверждённый контент
│   └── {date}-{topic}/
│       ├── text.md            # Финальный текст
│       ├── image.png          # Финальное изображение
│       └── meta.json          # Подписи под площадки
├── published/                 # История публикаций
│   └── {date}-{topic}.json    # post_id на каждой площадке
├── publisher/
│   ├── telegram.py
│   ├── vk.py
│   └── dzen_rss.py
├── publish.py                 # Точка входа
└── config.yaml                # API ключи, каналы, расписание
```

## 🔧 Стек

| Компонент | Инструмент | Команда |
|-----------|-----------|---------|
| Текст | Шекспир (skill) | `/skill agents/shakespeare` |
| Изображение | Рембрандт + Leonardo.ai | `/skill agents/rembrandt` |
| Апрув | Telegram (личка) | ручной выбор |
| Telegram | Bot API + `@ai_bureau` | `python-telegram-bot` |
| VK | VK API | `vk-api` |
| Яндекс Дзен | RSS + `@astrojs/rss` | `astro build` |

**Язык:** Python 3.10+
**Зависимости:**
```txt
python-telegram-bot>=20.0
vk-api>=11.0
pyyaml>=6.0
pillow>=10.0
```

## 📊 Цикл (1 пост)

| Этап | Время | Участие |
|------|-------|---------|
| 1. Шекспир пишет 3 варианта | 30 сек | Нет |
| 2. Ты выбираешь кнопкой в TG | 30 сек | ✅ |
| 3. Рембрандт рисует 2 картинки | 20 сек | Нет |
| 4. Ты выбираешь картинку кнопкой | 15 сек | ✅ |
| 5. Публикация на 3 площадки | 10 сек | Нет |
| **Итого на 1 пост** | **~2 мин** | **< 1 мин твоего времени** |
