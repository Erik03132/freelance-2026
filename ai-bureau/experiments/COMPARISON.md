# Сравнение двух подходов: видео-аудит vs готовое демо

## Подход 1: Видео-аудит (рекомендация западных практиков)

**Трудозатраты на 1 лида:** 20-25 минут
- 5 минут на изучение существующего сайта
- 5 минут на запись видео (одна экранка, без монтажа)
- 5 минут на загрузку в YouTube/Telegram
- 5 минут на отправку клиенту в WhatsApp/Telegram

**Что нужно:** только QuickTime на Mac, микрофон, заранее открытые вкладки

**Конверсия:** на западе 15-20% от просмотра в заявку на созвон
**Риски:** клиент может не посмотреть видео (открываемость ~40%)

**Масштабируемость:**
- 5 видео в день = 25 в неделю
- При конверсии 15% = 3-4 лида в неделю
- При конверсии в сделку 30% = 1 сделка в неделю
- При среднем чеке 120 000 ₽ = 480 000 ₽/мес выручки

---

## Подход 2: Готовое демо (твой вариант)

**Трудозатраты на 1 лида:** 2-4 часа
- 40 минут: быстрый анализ существующего сайта (структура, цвета, контент)
- 1-2 часа: сборка демо-главной (HTML/CSS/JS, адаптивная вёрстка)
- 30 минут: настройка голосового бота (Retell или простая JS-заглушка)
- 30 минут: создание llms.txt, Schema.org, GEO-оптимизация
- 30 минут: деплой на временный домен

**Что нужно:** редактор кода, GitHub Pages/Vercel для деплоя, Retell API для голосового бота

**Конверсия:** выше 25-30% — клиент видит готовый результат
**Риски:** 3-4 часа работы на лида, который может отказаться

**Масштабируемость:**
- 2 демо в день = 10 в неделю
- При конверсии 30% = 3 лида в неделю
- При конверсии в сделку 50% = 1.5 сделки в неделю
- При среднем чеке 120 000 ₽ = 720 000 ₽/мес выручки

---

## Вывод: когда какой подход применять

| Сценарий | Подход |
|----------|--------|
| Холодный лид, впервые видит вас | **Видео-аудит** (быстрее, меньше риска) |
| Тёплый лид, уже был контакт | **Готовое демо** (максимальная конверсия) |
| Массовый обзвон/рассылка | **Видео-аудит** (масштабируется) |
| Точечная работа по 1-2 тёплым | **Готовое демо** (лучше впечатление) |
| Нишевая атака (20+ целей) | Видео-аудит для 80% + демо для топ-20% |
| VIP-клиент, высокий чек | **Готовое демо** (показывает серьёзность) |

## Оптимальная стратегия: гибрид

1. **Неделя 1:** видео-аудиты по 5 клиникам в день (25 шт.)
2. **Конец недели:** из тех, кто ответил — выбираем 3 самых перспективных
3. **Неделя 2:** делаем готовое демо только для этих 3
4. **Итог:** охват 25 клиник → 5-8 ответивших → 3 демо → 1-2 сделки
5. **Выручка:** 120 000–240 000 ₽ за 2 недели работы при нагрузке ~3-4 часа/день
