# Как настроить голосового AI-агента: пошаговое руководство от SIP до первого звонка

**О чём статья:** технический гайд по настройке голосового агента. Полезно для тех, кто хочет понять, как это работает «под капотом».

---

Голосовой AI-агент — сложная система. Но если разобрать её на компоненты, всё становится понятно. Вот как это устроено на примере нашей платформы **Levitan**.

### Шаг 1. SIP-телефония

Голосовой агент начинается с номера. Мы используем **Mango Office** — российский провайдер с SIP-подключением.

На сервере (VPS, Ubuntu) поднимаем два компонента:

```
pjsua (порт 5060) — автоответ на входящий звонок
baresip (порт 5060) — воспроизведение аудио (WAV)
```

`iptables` разрешаем только трафик от Mango (IP 81.88.86.11) на UDP 5060 и RTP-диапазон 16384-32768.

```bash
iptables -A INPUT -s 81.88.86.11 -p udp --dport 5060 -j ACCEPT
iptables -A INPUT -p udp --dport 16384:32768 -j ACCEPT
```

### Шаг 2. Обработка звонка (вебхук)

Mango присылает callback на наш сервер при каждом событии: звонок поступил, абонент ответил, разговор завершён.

```
POST /api/webhook
{
  "event": "call_appeared",
  "call_id": "12345",
  "from": "+79001234567"
}
```

Наш **levitan-webhook** обрабатывает эти события и запускает сценарий.

### Шаг 3. Распознавание речи (STT)

Когда клиент что-то говорит, аудио сохраняется, и **Whisper** (локально на VPS) транскрибирует речь в текст.

```python
import whisper
model = whisper.load_model("base")
result = model.transcribe("call_12345.wav")
text = result["text"]  # "Когда будет доставка?"
```

Можно заменить на Yandex SpeechKit, если нужно выше качество (чуть дороже).

### Шаг 4. Обработка LLM

Текст отправляется в LLM (Gemini / Claude) с контекстом из RAG-базы знаний (ваши FAQ, регламенты, прайсы).

```
User: "Когда будет доставка?"
Context: [Заказ №12345, адрес: г. Азов, статус: в пути]
LLM: "Ваш заказ в пути, ориентировочное время — через 2 часа.
      Хотите уточнить адрес или перенести доставку?"
```

Smart Fallback: если LLM не уверена в ответе — задаёт наводящий вопрос. Если не помогло — переключает на оператора.

### Шаг 5. Синтез речи (TTS)

Ответ LLM озвучивается через **Fish Audio** или **Qwen Audio 3.0**. Модели поддерживают эмоциональные теги:

```
"Ваш заказ в пути! <happy>Прибудет через 2 часа</happy>"
```

Аудио воспроизводится через baresip в линию.

### Шаг 6. Цикл диалога

Агент не просто отвечает один раз — он ведёт диалог:

```
Клиент: Когда доставка?
Агент: Ваш заказ в пути, примерно через 2 часа.
       Хотите уточнить адрес?
Клиент: Да, я на работе, привезите в офис.
Агент: Принял. Меняю адрес доставки на {ваш офис}.
       Подтверждаете?
Клиент: Да.
Агент: Готово. Что-то ещё?
```

Цикл повторяется, пока клиент не завершит разговор или не потребуется эскалация.
