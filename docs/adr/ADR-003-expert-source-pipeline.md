# ADR-003: Expert Source-Pipeline (разбор статей/ссылок пользователя)

**Дата:** 2026-08-14
**Статус:** Accepted
**Контекст:** В сеансах режима «Эксперт» пользователь кидает URL статей/репозиториев
для разбора. Нужен единый, воспроизводимый алгоритм, чтобы любой сеанс/агент
обрабатывал источник одинаково: без веры на слово, с привязкой к нашему стеку,
с фиксацией и (по команде) реализацией под защитой тестов.

## Решение — 6 шагов

1. **Верификация (анти-авторитет).** Ресурс проверяется на реальность ДО применения:
   `webfetch` статьи / `gh` для репозиториев / `websearch` для перекрёстной сверки
   (автор, дата, звёзды, лицензия, независимые подтверждения). Утверждения авторов
   НЕ принимаются на веру (AGENTS.md §13).
2. **Разбор архитектуры.** Выделить ключевые паттерны/решения: что, как, чему учимся.
3. **Маппинг на стек.** Сопоставить с `freelance-2026` (OpenCode, OmniRoute,
   claude-mem, skills/, AGENTS-каскад, ai-defender, eval_gate). Отбросить неприменимое
   и вредное по жёстким границам (п.4).
4. **Границы (hard rules):**
   - офенсивные эксплоиты (BH) — ТОЛЬКО defensive, без авторизованного пентеста не делать;
   - де-алигнмент моделей / uncensored (HTC) — НЕ реализовать;
   - приватность/РФ-сервисы — ADR-002 (прокси-независимость, MIT-страховка).
5. **Запись в ACTIVE_TASKS.md.** Секция с ID-задачами по префиксу источника
   (DSH/KWP/BH/HTC/AR/ME/BK/HZ/LL + нумерация). Вердикт обязателен:
   `проверено src → принято | граница | гипотеза`. Каждая задача — конкретный
   следующий шаг, не абстракция.
6. **Реализация по триггеру.** По «да»/«продолжай» пользователя — высокоценные
   задачи → конкретный код в репозитории (ponytail: stdlib, детерминированность)
   + **eval-driven** (прогон `tests/eval_*.py`). Статус закрытия — **Verified**
   (доказано тестами/смоуком), НЕ просто Fixed (SA-1).

## Альтернативы
- Полагаться на саммари статьи без верификации — отвергнуто (анти-авторитет, AGENTS §13).
- Реализовать всё подряд без границ — отвергнуто (HTC/BH-офенсив).
- Коммитить без «да» пользователя — отвергнуто (AGENTS: не коммитить без просьбы).

## Последствия
- Скилл `expert-source-pipeline` загружается агентом при дропе URL.
- Каждый источник оставляет след в ACTIVE_TASKS.md + (при реализации) в eval-сюитах.
- Воспроизводимость между сеансами/агентами (один алгоритм, одни ID-префиксы).
