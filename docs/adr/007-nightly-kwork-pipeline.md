# ADR-007: Ночной конвейер поиска кворков (Sherlock → Batrak → Chief)

- **Статус:** принято (2026-08-25)
- **Контекст:** Приоритет = поиск работы. Нужен ночной полу-авто конвейер:
  Sherlock ищет подходящие кворки, Batrak пишет отклики в стандарте v3,
  Chief собирает — утром Игорь копирует готовое в Kwork вручную (анти-бан).
- **Решение:**

## 1. Роль конвейера (полу-авто, НЕ авто-отправка)
- Sherlock ищет + фильтрует кворки (сладкий сегмент по калибровке jobhunter).
- Batrak генерит отклик в стандарте v3 (HOOK→MATCH→PROOF, «С уважением, Игорь»,
  ссылка freelance-2026, готовность к тестовому, без «откликаюсь»/«Буду рад»).
- Chief собирает итог, пишет в `docs/outbox/<kwork>.md` + аппендит в `leads.md`.
- **Отправка — только Игорь вручную.** Никаких auto-send (бан HH/Kwork).

## 2. Фильтр по калибровке (SSoT = skill jobhunter)
ИДЁМ в сегмент:
- AI-инженер / RAG / эмбеддинги / векторные БД.
- Telegram-боты (aiogram) + CRM (Bitrix24) + Voice (Mango) + AI.
- Парсеры / скрипты контроля сделок / транскрибация (faster-whisper — реально есть).
- Прототипы сайтов / лендинги под ключ.
ОТСЕКАЕМ: Hardcore Senior/Lead Backend, Enterprise-легаси, BigTech алго-секции,
бюджеты ниже нашей цены (см. §3).

## 3. Стоимостная модель (ставка 1500₽/час = внутренний якорь)
- Kwork = фикс-цена за проект, «почасовка» не прокатит.
- Sherlock оценивает часы → `часы × 1500₽` = наша минимальная фикс-цена.
- Бюджет заказчика < нашей цены → отказ или урезанный скоуп (тип B/отсев).
## 4. Триаж A/B (Sherlock не драфтит всё подряд)
- **Тип A** (наш сегмент + бюджет ≥ нашей цены + лёгкий proof): драфт отклика + маленький живой proof.
- **Тип B** (погранично / дорого / неясно): только драфт письма, без сборки proof.
- **Отсев** (Hardcore Senior/Enterprise, < нашей цены, вне сегмента): не трогаем.

## 5. «Рыбка» = капсулированный proof-budget (≤30 мин, локально)
Готовим ЧАСТЬ работы заранее как фишку:
- роадмап + выполнен п.1, ИЛИ прототип сайта + деплой на GitHub Pages, ИЛИ
  бот-заглушка с частичной работой.
ОГРАНИЧЕНИЯ (guard):
- ≤30 мин, только локально / бесплатно, БЕЗ платных API и секретов.
- ТИРАЖИРУЕМ не сам заказ, а *дженерик-заготовку* (нейтральный репо, скрин/демо-ссылка),
  чтобы заказчик не спёр готовое и не ушёл. Реальную tailored-работу — уже за деньги.

## 6. Дедуп (не переписывать один кворк каждую ночь)
- Хранить ID просмотренных кворков в БД (sqlite `freelance.db` уже есть).
- Драфтить только НОВЫЕ. Иначе утром — куча копий одного отклика.

## 7. Anti-бан при ночном парсинге
- Kwork за Qrator: задержки 5–15с рандом, использование `cookies/kwork.json`,
  не более N запросов/ночь. Без циклов без пауз.

## 8. Жёсткий guard: free-only LLM, NO auto-send
- `package.json` старого агента тащит `@google/genai` (платно) — ЗАПРЕЩАЕМ авторасход.
- Только free-модели (hy3-free / локальный Ollama). Ни одной кнопки отправки.
## 9. Доставка в 9:00 (SSoT = файл, TG потом)
- Ночной крон пишет в `docs/outbox/<kwork>.md` + аппендит в `leads.md`.
- TG-дайджест в чат 176203333 добавим, КОГДА починим gateway (см. ACTIVE_TASKS:
  TG-gateway не свитчит профили; OmniRoute мёртв). Стартуем на файле — гарант просмотра.

## 10. Площадки (отдельные фазы)
- Ф5а: HH (ПАРСИНГ, НЕ API — hh API соискателей закрыт с 15.12.2025), с задержками.
- Ф5б: международные (Upwork/Fiverr) — позже, отдельно.

## 11. Обратная связь (фильтр учится)
- Игорь помечает «выиграл / нет» в `leads.md` → триаж A/B корректируется.

## Приложение: результат аудита Ф0 (read-only, 2026-08-25)
- `src/` содержит только 3 файла: `mcp-servers/bitrix.ts`, `mcp-servers/avito.ts`,
  `agents/specialists/design.ts`. `src/index.ts` (упомянут в package.json) **ОТСУТСТВУЕТ**.
- `dist/` нет. Полноценный скрайпер Kwork (логика `dev:kwork`) **не сохранился** в репо.
- Есть: `data/cookies/kwork.json` (домен .kwork.ru), `reports/*.json` (март–апрель 2026,
  за проход 2–5 кворков), `freelance.db` (sqlite). Апрельский фильтр ловил игры/эмодзи — НЕ наша калибровка.
- **Вывод:** старый агент = нерабочий задел (только MCP-серверы Avito/Bitrix + design-агент).
  Строим конвейер ПОЧТИ с нуля, переиспользуя cookies + формат reports как образец.
- Kwork с Мака ходит напрямую (200 OK, без прокси) — парсинг реален.
