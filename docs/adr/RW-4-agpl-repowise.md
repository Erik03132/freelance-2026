# RW-4: Решение по лицензии AGPL-3.0 (repowise)

> Дата: 06.08.2026 · Статус: РЕШЕНО (архитектурное решение, claude-mem kind=decision)

## Суть
repowise лицензирован AGPL-3.0 (копилефт: любое распространение/сетевое
взаимодействие с изменённым кодом требует открытия исходников).

## Решение
1. **repowise использовать ТОЛЬКО на внутренних репо** (open-code, freelance-agent,
   ai-eggs и т.п.) — как dev-инструмент, не встраивая в продукты клиентов.
2. **В клиентские продукты не встраивать** — вместо этого реализовывать паттерны
   ADR-003 собственным кодом (мой код — моя лицензия), либо использовать
   repowise как внешний процесс в CI (dev-only), не в дистрибутиве.
3. Зафиксировать в CLAUDE.md проекта: «repowise — AGPL, только внутреннее использование».

## Обоснование
- Наши клиентские проекты (sinergy, svo-start, dashboards) — коммерческие;
  AGPL-код в них = обязательство открыть исходники → недопустимо.
- Для внутренних задач (аудит, планирование, ревью) копилефт не мешает.
