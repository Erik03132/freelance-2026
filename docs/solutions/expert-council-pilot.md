# Expert Council Pilot — сравнение 3 кейсов

**Дата:** 2026-08-20 · **Автор пилота:** Hermes (Chief) · **Задача:** ES-12

## Что проверяли

Сравнить **одиночный Expert** vs **Expert Council (4 роли)** на 3 кейсах из эксперт-сессии 19-20.08.2026.

## Метод

На каждый кейс дать **два** разбора:
1. Одиночный — как в этой сессии делалось (то, что уже записано)
2. Council — пропустить через 4 роли, посмотреть что добавилось/пропустилось

Кейсы:
- **CodeGraph** (colbymchenry/codegraph, 67k★, локальный MCP-граф кода) — реальный технический инструмент
- **Попов «9 кейсов Hermes + Multica»** — продающее видео без конкретики
- **Hermes Bot Mode** — встроенная фича Hermes для команд ботов

---

## Кейс 1: CodeGraph

### Одиночный Expert (из этой сессии)

**Что:** локальный MCP-сервер, парсит репо в SQLite-граф, отдаёт агенту через один tool. 67k★.
**Зачем:** закрывает наш ADR-003 (graph layer), пилот на agent-lab — 9 файлов → 1.6 сек на индекс, tool calls падают на 80%.
**Нужно ли нам:** ДА. Записан как ES-10, пилот прошёл успешно (см. `codegraph-pilot.md`).

### Council review

**Expert:** то же + по итогам пилота работает. Берём.

**Skeptic:**
- Rust + SQLite — обновления безопасности на Игоре (нет auto-update)
- Один tool по умолчанию — если модель привыкнет к нему и сломается, откат = переучить. Workaround: переменная окружения для других tools
- VS Code бенчмарк автора = 11k файлов; наш agent-lab = 9 файлов. Цифры не масштабируются линейно
- Автор сам признаёт +80% retrieval context в конце сессии
- **Red lines:** не подключать к рабочим прод-проектам (Mango, Bitrix24) без отдельного пилота; не ставить обязательным для всех агентов

**Analyst:**
- 67 092★, 4 259 forks, активный (push 08.08.2026), лицензия MIT
- Стек: Rust-движок, MCP-протокол, поддержка 20+ языков
- Аналоги: Serena (LSP-based, может редактировать), Codebase Memory MCP (pure C, тот же подход), Cursor native indexer (в планах)
- Стоимость: 0₽ (open source), время на пилот = 5 мин
- **Comparison:**

| Инструмент | Подход | Плюс | Минус |
|---|---|---|---|
| **CodeGraph** | SQLite-граф, MCP, Rust | зрелый, широкие языки, активный | read-only |
| Serena | LSP-based | может редактировать | тяжелее ставить |
| Codebase Memory MCP | pure C | лёгкий | мало звёзд |

**Financier:**
- Стоимость: 0₽, 5 мин установки
- Текущий пилот: 0₽ (мы сделали)
- ROI: на agent-lab экономия ~80% tool calls на структурные вопросы. В месяц если 100 таких вопросов × экономия 5 сек × 4 токена/сек = 0.0001₽ напрямую, но главный эффект — время Игоря
- Hidden costs: обучение Игорька/Кулибина (~30 мин), поддержка при обновлениях, если MCP сломается — откат
- **Total: 0₽ + 30 мин на онбординг команды**

**Verdict:**
Что: локальный MCP-граф кода, 67k★
Зачем: ADR-003 закрыт, пилот прошёл
Берём: **да, продвигаем в инфраструктуру**
Не берём потому что: не подключаем к прод-проектам без отдельного пилота

### Что добавил council vs одиночный

- **Skeptic:** риск по 1 tool по умолчанию + антипаттерн «не подключать к прод-проектам без пилота». Одиночный Expert это не выделил.
- **Analyst:** звёзды/лицензия/аналоги — одиночный тоже упоминал, но без таблицы
- **Financier:** ROI в час Игоря, не в токенах. Одиночный не считал

**Council полезнее для серьёзного решения.** Подтверждает гипотезу ES-12.

## Кейс 2: Попов «9 кейсов»

### Одиночный Expert

**Что:** продающее видео Дмитрия Попова (COMANDOS AI) про 9 кейсов на Hermes + Multica. Ничего конкретного.
**Зачем:** для новичков — обзор.
**Нужно ли нам:** **НЕТ.** Ничего нового, продающее.

### Council review

**Expert:** то же. Шум.

**Skeptic:**
- Multica = внешний SaaS, автор продвигает. Конфликт интересов: 90+ компаний «внедрение», язык как у инфо-цыган
- Hermes Bot Mode в видео = rebrand того что мы делаем руками (Шерлок/Ботман/Кулибин)
- «Рост компании от 30 000 до 2 470 000₽» — без источника, без методики, без сравнения с контрольной группой
- Здоровье-агент = нормально для личного использования, но без референсов на доказательную медицину
- **Red lines:** не подключаться к Multica, не покупать «гайд по настройке», не воспринимать как обучающий материал

**Analyst:**
- Канал 7k+ подписчиков, реальный предприниматель, не pure-инфобиз
- Но формат видео: 28 мин, 0 конкретных метрик, 0 ссылок на исходники, 0 воспроизводимых шагов
- Сравнение с каналами: AI Stack Engineer (конкретные репо, бенчмарки, реальные цифры) → качественно другой класс

**Financier:**
- Стоимость: ничего (видео бесплатное)
- Если бы купили «гайд по настройке» = потеря времени + денег + потенциально токсичные практики
- Hidden costs: если Игорь начнёт копировать архитектуру Попова (VPS + Telegram + SaaS Multica) → уход от наших принципов (own data, no external SaaS для секретов)

**Verdict:**
Что: продающее видео
Зачем: ничему конкретному не учит
Берём: **нет**
Не берём потому что: нет воспроизводимых шагов, конфликт интересов автора

### Что добавил council

- **Skeptic:** конфликт интересов Multica + инфоцыганские формулировки. Одиночный Expert упомянул «продающее», но без деталей почему.
- **Financier:** hidden cost — уход от наших принципов. Одиночный не оценивал.

## Кейс 3: Hermes Bot Mode

### Одиночный Expert

**Что:** встроенная фича Hermes Desktop для команд ботов (UI, @mentions, cron на каждого). Дублирует наши скиллы.
**Зачем:** для тех, кто хочет рулить агентами через UI.
**Нужно ли нам:** НЕТ. Дубль.

### Council review

**Expert:** то же. Дубль нашего Шерлок/Ботман/Кулибин через скиллы.

**Skeptic:**
- Требует v0.20.3+ и запущенный gateway (`hermes gateway install`) — это **привязка к инфраструктуре Hermes**. У нас VPS Timeweb, gateway надо поднимать отдельно
- Free tier обычно = ограниченный runtime или метрики — нужно проверить лимиты
- Если завтра Nous Research изменит pricing модели или закроет tier — мы в заложниках
- **Red lines:** не переходить на Bot Mode как основной канал руления агентами до отдельного пилота

**Analyst:**
- Видео 4k просмотров за 2 дня — интерес есть
- В описании: «Bot Mode», «Multi-agent», «MCP» — современный стек
- Сравнение: Antigravity Brain (наш собственный) → полный контроль, свои агенты, нет внешней зависимости

**Financier:**
- Стоимость: 0₽ на старте (free tier), но потенциально платный за runtime/модели
- Время: попробовать 30 мин, понять нужно ли — 1 час
- ROI: если даст **внешний UI для Игоря** (он сейчас в терминале) — может быть ценно
- Hidden cost: привязка к вендору, миграция если сломается

**Verdict:**
Что: дубль нашего, но с UI
Зачем: для тех кто не любит терминал
Берём: **позже, если Игорь попросит UI для агентов**
Не берём сейчас потому что: дубль, нет явной пользы над текущим

### Что добавил council

- **Skeptic:** привязка к вендору (важный риск для on-prem стратегии). Одиночный Expert не выделил.
- **Analyst:** сравнение с Antigravity Brain (наша альтернатива). Одиночный Expert упомянул «продукт Hermes вместо ручных скиллов», но не в контексте нашей альтернативы.
- **Financier:** ROI от UI (если Игорь хочет). Одиночный не считал.

## Итог пилота

| Кейс | Одиночный вердикт | Council вердикт | Council добавил |
|---|---|---|---|
| CodeGraph | Берём | Берём | Red lines (не подключать к прод-проектам), ROI в час Игоря |
| Попов | НЕТ | НЕТ | Конфликт интересов Multica, hidden cost ухода от принципов |
| Hermes Bot Mode | НЕТ | Позже | Привязка к вендору, ROI от UI |

**Council полезнее** на серьёзных решениях:
- Ловит **скрытые риски** (вендор, конфликт интересов, hidden cost)
- Даёт **числа** (ROI, стоимость)
- Формирует **red lines** — то, что одиночный Expert часто пропускает

**Council бесполезен** на мелочах: +3-4x токенов на вопрос, где ответ «нет, мелкий шум».

## Решение

**Оставляем Council как опциональный скилл** для:
- Нового класса инструмента (≥100к₽ годовой импакт или ≥10ч в неделю работы)
- Стратегических решений (куда идём, что строим)
- Явного триггера пользователя («давай через council», «совет экспертов»)

**Одиночный Expert остаётся дефолтом** для остальных 90% разборов.

**Стоимость:** Council = 4x токенов одиночного. Использовать осознанно.
