# 20260808_notebooklm-mcp _ PyPI

## Суть (2-3 предложения)
notebooklm‑mcp — production‑ready MCP‑сервер, автоматизирующий работу с Google NotebookLM на базе FastMCP v2. Он поддерживает несколько транспортов (STDIO, HTTP, SSE), сохраняет сессию Google в профиле Chrome для headless‑режима и предоставляет богатый CLI, UV‑менеджер зависимостей и Taskfile с 20+ автоматизированными задачами. Благодаря Pydantic‑валидации и автогенерации схем сервер легко интегрируется с LangGraph, CrewAI и другими фреймворками AI‑агентов.

## Ключевые идеи
1. notebooklm‑mcp реализован как MCP‑сервер на FastMCP v2, обеспечивающий декоратор‑based регистрацию инструментов и автоматическую генерацию схем.  
2. Поддерживает múltiplos транспорта (STDIO, HTTP, SSE) и использует persistent Chrome profile для сохранения Google‑аутентификации между запусками.  
3. В комплекте идут UV‑менеджер пакетов, Taskfile с готовыми скриптами для зависимостей, тестирования, линтинга, сборки и деплоя, а также удобный CLI для быстрого старта через Docker, pip или UV.  
4. Типобезопасность гарантируется Pydantic‑валидацией параметров MCP‑инструментов, что упрощает интеграцию с внешними фреймворками.  
5. После первоначального логина сервер может работать в полностью фоновом режиме без интерактивного ввода.

## Паттерны/фреймворки
- **FastMCP v2** — декоратор‑based фреймворк, автоматически генерирующий JSON‑схемы и ускоряющий регистрацию MCP‑инструментов в ≈5 раз.  
- **UV** — современный менеджер пакетов и виртуальных окружений, обеспечивающий молниеносную установку и изоляцию зависимостей.  
- **Taskfile** — набор готовых скриптов для управления зависимостями, тестирования, линтинга, сборки и запуска серверов, упрощающий DevOps‑ workflow.  
- **Pydantic‑валидация** — гарантирует типобезопасность параметров MCP‑инструментов и автоматически проверяет входные данные при вызове.  
- **Persistent Chrome profile** — сохраняет куки и токены Google‑аккаунта, позволяя последующие запуски работать в headless‑режиме без повторного логина.

## Применимо к нам
- Использовать notebooklm‑mcp как готовый MCP‑инструмент в агентах LangGraph/CrewAI для автоматического чтения, обновления и выполнения ячеек в Google NotebookLM.  
- Интегрировать persistent Chrome profile в пайплайны агентов, чтобы избежать повторной авторизации при каждом запуске и обеспечить стабильный доступ к нотам.  
- Применять FastMCP v2 для быстрого создания собственных MCP‑инструментов (например, обёрток над внутренними API) с автогенерацией схем и Pydantic‑валидацией, сокращая время разработки.  
- Включить UV и Taskfile в CI/CD процессы наших AI‑агентов для мгновенного развертывания окружений, запуска тестов и линтинга перед деплоем новых версий инструментов.  
- Использовать Pydantic‑схемы при построении evals‑pipeline, чтобы автоматически проверять корректность входных и выходных данных агентов, работающих с NotebookLM.
