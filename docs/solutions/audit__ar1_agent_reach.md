# AR-1: Agent-Reach — НЕ ПРИМЕНИМ в исходной формулировке

> Дата: 06.08.2026

## Что выяснено
- npm-пакет `agent-reach` v0.3.3 — это **OpenClaw Agent Discovery Extension**
  (Nostr-сеть публикации capability-карточек агентов), НЕ CLI с флагом `--safe`.
  `package.json` не содержит `bin` — установить и запустить `agent-reach --safe`
  невозможно.
- Для работы требует: OpenClaw (другой агентный хост), Nostr-конфигурацию
  (identity/ключи), сборку расширения (`npm run build`) в `~/.openclaw/extensions/`.

## Вывод (HT-3: имя отказа)
- Задача AR-1 в формулировке ACTIVE_TASKS («Установить Agent-Reach `--safe --dry-run`,
  включить ТОЛЬКО zero-config каналы web/YouTube/GitHub/RSS/Exa») описывает
  инструмент, которого не существует в таком виде. Возможно, имелся в виду другой
  продукт («agent reach» как сервис мониторинга) — в реестре решений не найден.
- Принято решение: **не внедрять** — неизвестная цель, требуется сетевая
  инфраструктура Nostr/OpenClaw, ценность для наших агентов не подтверждена.
