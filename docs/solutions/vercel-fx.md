# Vercel fx — ультралёгкий coding-агент (один бинарь)

**Что:** coding-агент от Vercel Labs. 6,3 МБ, написан на Zig, один автономный файл,
запуск ~10 микросекунд. Не нужны Node.js/Python. Цепляется к любой модели —
локальной или облачной. Есть WASM-версия (<6,3 МБ). Исходник:
https://github.com/vercel-labs/fx

**Где юзать:** лёгкий рантайм для песочниц, тестирования моделей, оценки качества,
внутренней инфры. В тему «локалка нужна» — минималистичная альтернатива тяжёлым
рантаймам (browser-use / macos-harness громоздки по зависимостям).

**Отличия от нашего стека:** model-agnostic (любой провайдер, включая локальный
через OmniRoute), ноль рантайм-зависимостей, мгновенный старт. Дополняет, а не
заменяет macos-harness (нет computer-use) и Ornith (не модель).

**Риски:** проект свежий, экосистема минимальна; не заменяет полноценный
agent-framework для сложных задач бюро.

**Статус:** Кандидат. Записано в биотеку. Потенциально юзать как лёгкий запускатель
агентов поверх локальных моделей (Ornith-1.5-9B / Qwen-uncensored).
