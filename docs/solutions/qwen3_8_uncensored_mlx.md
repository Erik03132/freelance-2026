# Qwen3.8-27B-Uncensored-MLX — локальная «без цензуры» LLM на Mac

**Что:** нецензурированный форк Qwen3.8-27B в сборках MLX (2/4/6/8 бит) для запуска
на Mac (Apple Silicon). Выполняет запросы, от которых обычная версия отказалась бы
(вредоносные/неэтичные/незаконные). Сохраняет зрение, рассуждение и tool-calling,
контекст до 262K токенов. Источник:
https://huggingface.co/orcarouter/Qwen3.8-27B-Uncensored-MLX

**Где юзать:** локальный агентный «мозг» на Mac без цензуры и без отправки данных
наружу. В тему «локалка нужна» (сосед — ES-13 Ornith-1.5). Конкурент/дополнение:
Ornith агентно заточен и MIT, Qwen-uncensored проще по затратам RAM и без ограничений.

**Риски:** отсутствие встроенных guardrails → по запросу выдаёт инструкции по
ВПО/мошенничеству/оружию. Только для локальных экспериментов и задач, где цензура
мешает; НЕ в прод и НЕ в агентов, которые ходят в сеть/пишут файлы без присмотра.
Лицензию исходника уточнять (uncensored-форки обычно под той же, что base).

**Статус:** Кандидат (ограниченно). Записано в биотеку. Рассматривать как локальную
альтернативу «мозгу» для sandbox-задач; изолировать от сети и ФС прод-агентов.
