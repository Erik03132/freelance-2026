# Claude Code session efficiency — выжимка стоимости токенов

**Что:** практики (НЕ инструмент) снижения стоимости агентных coding-сессий.
Источник: https://claude.com/blog/maximizing-the-value-of-your-claude-code-sessions
(Lydia Hallie, 14.08.2026). Большей частью специфично для Claude Code, но
принципы (стабильность префикса кэша, subagent-изоляция шума) применимы к
OpenCode/Codex/Hermes.

**Суть (экономика токенов):**
- Биллинг = время инференса. 3 рычага цены: модель, input vs output
  (output ~5x input), кэш (чтение 0.1x, запись до 2x).
- Prompt cache ключается по префиксу запроса (порядок: tool defs → system →
  conversation с `CLAUDE.md` спереди). Любое изменение В ПРЕФИКСЕ → пере-префилл
  всего за полную цену.
- Что бьёт кэш: `/model`, `/effort`, Fast mode, `/compact`, истечение времени
  (1ч на подписке / 5мин на API-ключе; `ENABLE_PROMPT_CACHING_1H=1` → 1ч).

**Практики (в порядке влияния на цену):**
- `/clear` между задачами — не тащить чужой контекст.
- `/model` и `/effort` — один раз в свежей сессии; смена посреди = re-prefill.
- @-упоминание файлов вместо называния — экономит Read/поиск.
- Тихие флаги на шумные команды ИЛИ subagent — вывод команды висит в
  сессии до конца.
- `/context` раз в сессии — что загружено (`CLAUDE.md`, MCP), выкинуть лишнее.
- `/compact` перед перерывом — кэш истекает за час; сжать пока в кэше дешевле.
- `MAX_THINKING_TOKENS=0 claude` — выключить thinking на сессию (кроме Fable 5).

**Вес:** 0 (знание/практика, не пакет). Диск не тратит.

**Когда юзать:** любая агентная coding-сессия в нашем стеке
(OpenCode/ZCode, Codex, Hermes subagents) — чтобы не сливать токены на
перечитывание и re-prefill.

**Риски/ограничения (экспертиза, авг-2026):**
- Механики (TTL кэша, `/model` `/effort`) специфичны для Claude Code; у
  OpenCode/Codex/Hermes свои кэш-политики — проверять под каждый бэкенд.
- Кривые в посте — «иллюстрация, не бенчмарки» (автор признаёт).
- Не покрывает КАЧЕСТВО контекста и риск потери деталей при частом `/compact`.
- Самое важное для нашего стека: не менять модель посреди сессии — прямо
  бьёт в наш OmniRoute auto/free-coding каскад (смена модели = re-prefill
  + скачок цены). Стабилизировать префикс = главный рычаг.
