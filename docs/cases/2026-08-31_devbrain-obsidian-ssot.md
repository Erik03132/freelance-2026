# devbrain — Obsidian SSoT для мультиагентного кодинга

**Автор/источник:** `DycandX/devbrain` (30.08.2026, GitHub, https://github.com/DycandX/devbrain) · ★1 · активен (pushed 31.08.2026) · лицензия — (проверено через `api.github.com`)

**Суть (2-3 строки):** open-source хаб «мозга» для AI-агентов: подключает Google Antigravity IDE / Claude Code / Hermes / OpenCode напрямую к локальному Obsidian-хранилищу через MCP. Даёт 4 нативных memory-toolа — семантический гибридный поиск (FastEmbed CPU ONNX + Rank-BM25), получение контекста проекта, запись логов сессий, загрузка скиллов.

 Единый источник истины для команд агентов.



**Стек:** Obsidian Vault + Model Context Protocol (FastMCP) + Hybrid Semantic Search (FastEmbed CPU ONNX + Rank-BM25) + CLI (Typer/Rich). Подключается авто-регистрацией в `~/.gemini/antigravity/mcp_config.json` и `~/.claude.json`. Стандартная 7-папчовая таксономия хранилища (`00_System/…90_Agent_Inbox/`». Aгенты: Antigravity, Claude Code, Hermes, OpenCode.



**Что применимо у нас:** [ЧАСТИЧНО] — закрывает ровно наш ARCH-001/002 (общая база знаний Mac↔VPS, изолированные профили)、но у нас уже есть: Obsidian-хранилище, `hermes-knowledge-sync` (git-мост Mac↔VPS, `skill-router` ленивая загрузка скиллов. НОВОЕ тут: **гибридный поиск (FastEmbed/BM25) через MCP для Hermes** и привязка «профиль/проект → контекст из хранилища» — кандидат на достройку нашей базы, не полный переход.



**Цифры/бенчмарки:** звёзд/форков — нет громких. Публичных бенчмарков нет (n/a). Проверено через API: 1★, pushed 31.08 — активный, но ранний микропроект一人.



**Trade-off:** позиционирован под Obsidian + привязка к 2-м IDE (Antigravity/Claude) жёстко в setup-скриптах; большую ценность даёт сама схема (7-папок, memory-таксономия, гибридный поиск), а не код-репо (ранняя стадия, ★1.



**Сравнение с альтернативами:** vs наш `hermes-knowledge-sync` — тот синхронизирует ФАЙЛЫ (git, без поиска; тут — живой retrieval+MCP через query к хранилищу. vs `llm-wiki` Karpathy — тот построен на markdown-KB с другим интерфейсом. devbrain ближе к нашем Obsidian-подходу за счёт гибридного поиска.
