# hermes-companion — mobile-first control plane для Hermes

**Автор/источник:** `forcewake/hermes-companion` (30.08.2026, GitHub, https://github.com/forcewake/hermes-companion) · ★0 · MIT · активен (pushed 30.08.2026, дизайн-стадия)

**Суть (2-3 строки):)** защищённая, мобильно-ориентированная панель управления для Hermes Agent: **Telegram Mini App** (первичная мобильная поверхность) + та же аппка как **Web/PWA** вне Telegram + **бот-уведомления**, обёрнутые typed control plane'ом с опциональным локальным bridge. Сам Hermes не модифицируется. UI — Discord-тёмный дизайн-контракт, capability-gated контроль, stage-based прогресс (без выдуманных процентови.

**Стек:** Telegram Mini App + PWA/Web + Telegram Bot API + typed control plane + локальный bridge（опц.）。

 Hermes Agent ядро не трогается.
