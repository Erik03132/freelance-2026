# codegraph — локальный knowledge-graph для кода, MCP

**Автор/источник:** AI Stack Engineer (YouTube, 17.08.2026, [l9XqpSaYHTs](https://www.youtube.com/watch?v=l9XqpSaYHTs)) · repo [colbymchenry/codegraph](https://github.com/colbymchenry/codegraph) · 67 092★ / 4 259 форков · активный (push 08.08.2026) · лицензия есть · MIT по описанию.

**Суть (2-3 строки):** парсит репо в локальный граф кода (функции, классы, вызовы, импорты) в SQLite, отдаёт агенту через MCP как один tool `codegraph_explore`. Агент спрашивает структуру → получает исходники + call chain + blast radius, не грепает и не открывает файлы руками. 100% локально, без ключей, без облака.

**Стек:** Rust-движок (20+ языков в компиле + фоллбэк шире), SQLite в `.codegraph/`, MCP-сервер, авто-sync через file watcher (~2 сек). Поддерживает OpenCode + Claude Code + Codex + Cursor + Hermes Agent (явно в описании репо).

**Что применимо у нас:** [ДА] — закрывает **ADR-003 (graph layer)** из нашего AGENTS.md, который заявлен, но не реализован. У нас `~/freelance-2026/agent-lab` — репо подходящего размера для пилота.

**Бенчмарк автора (7 репо × 4 прогона, VS Code/Django/Tokio/Excalidraw/Gin/OkHttp/Alamo):**
- 88% меньше tool calls, 53% быстрее, 62% меньше токенов, 44% дешевле
- VS Code (11k файлов): 28 calls / 2+ мин / $1.80 → **2 calls / 58 сек / $0.53**
- File reads = 0 на всех 7 репо
- Linux kernel (70k файлов / 2M символов): 12 мин на 2 ядра / 6 ГБ RAM
- Auto-тест discover через `codegraph_affected` (git diff → какие тесты реально трогает) — экономит CI build minutes

**Trade-off (автор честно признаёт в README):**
- +80% retrieval context сидит в окне после сессии (VS Code: 67k vs 18k токенов остатка)
- На длинных сессиях с маленькой моделью это съедает контекст — нужен план
- Выигрыш по tool calls, проигрыш по размеру контекста в конце. Оба эффекта одновременно.

**Сравнение с альтернативами (из видео):**
- **Serena** — построен на language servers, может редактировать код (как IDE). CodeGraph — read-only, только структурные вопросы.
- **Codebase Memory MCP** (DeusData, ES-8d в нашей очереди) — pure C, тот же подход. CodeGraph зрелее и шире по языкам.
- **Anthropic/OpenAI/Cursor** — рано или поздно выпустят свои индексаторы. CodeGraph выживает за счёт портативности: один граф работает на любого агента через MCP.

**Известные подводные камни (из видео):**
- После `install.sh` инсталлятор кладёт codegraph в PATH, но не обновляет уже открытый терминал → нужно **открыть новый**, иначе `command not found`.
- `codegraph install` (отдельная команда после install.sh) — это то, что подключает MCP к агенту. Люди пропускают.
- Один tool по умолчанию (`codegraph_explore`) — автор измерил, что агенты выбирают лучше с одним сильным, чем с меню слабых. Остальные (node/search/callers/callees/impact/files/status) спрятаны, можно вернуть переменной `codegraph_mcp_tools`.
- Тестовый git pull в другом терминале подхватится автоматически при reconnect (catch-up check).
- Телеметрия анонимная (команды и языки, не код/пути). Выключается: `codegraph telemetry off`.

**Когда НЕ ставить:** маленький сайд-проект <300 файлов — автор сам говорит, что эффект «roughly even». Реальная экономия начинается от больших репо.
