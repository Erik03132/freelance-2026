# hermes-snowflake — Hermes на Snowflake + прокси-совместимость провайдера

**Автор/источник:** `fbattaglieri-snowflake/hermes-snowflake` (26.08.2026, GitHub, https://github.com/fbattaglieri-snowflake/hermes-snowflake) · ★0 · лицензия NOASSERTION(нестандарт,) · активен (pushed 31.08.2026) · независимый проект Франческо Баттальери (через Snowflake Cortex Code), НЕ офиц. релиз Nous/Snowflake (явный disclaimer).



**Суть (2-3 строки):)** деплой Hermes Agent на Snowflake Snowpark Container Services (SPCS): персистентный блок-сторадж, **Cortex AI-совместимостьный прокси**, Tailscale-доступ клиентов, деплой через GitHub Actions OIDC. Ключевое: Hermes говорит по OpenAI Chat Completions, а Snowflake Cortex **отклоняется от спеки в 5 точках**, ломающих штатных клиентов — прокси (`cortex_proxy.py`) внутри контейнера решает все 5 за минималистичный Python-процесс.



**Стек:** Python (без зависимостей прокси), aiohttp, Hermes (`hermes serve`), Snowflake Cortex (CLI-compatible OpenAI протокол), Tailscale (DERP relay TCP/443), GitHub Actions OIDC, блок-сторадж SPCS.



**Что применимо у нас:** [ЧАСТИЧНО] — сама платформа (Snowflake) у нас нет и не нужна. Но **урок про 5 типовых расхождений OpenAI-совместимых провайдеров** — ровно наша боль: мы прошли 401/data-форматы с `opencode-zen` (`/zen/go/v1`→`/zen/v1`) и OmniRoute/auto-мёртвые каскады. Паттерн «тонкий тонкий прокси-адаптер между Hermes и провайдером, чинящий девиации» — релевантен для нашего OmniRoute/кастомного gateway. **Берём паттерн, не платформу.



**Цифры/бенчмарки:** 5 задокументированных несовместимостей(таблица в README):`max_tokens` vs `max_completion_tokens`; пустой `finish_reason`; `tools`+`reasoning_effort` взаимоисключаемы; `GET /v1/models`→404; токен через `/snowflake/session/token` вместо `Authorization`。 Проверено по README + API(★0, pushed 31.08.



**Trade-off:** решение узкое под Snowflake; но каталогизация несовместимостей —translateable на любой OpenAI-совместимый провайдер. Автор явно дисклеймит независимость —это «сделал на коленке и проверено на живом деплое», не коммерческий продукт.



**Сравнение с альтернативами:** vs наш путь с opencode-zen (лечили 401 ручной правкой endpoints в 9 профилях) — тут предлагается **многоразовый прокси**, а не конфиг-правки. vs OmniRoute(хаб провайдеров)—— тот роутит между готовыми, этот чинит один несовместимый. Взаимодополняюще.
