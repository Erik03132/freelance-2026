## knowledge-factory — модель знаний vs RAG, provenance, fact-check
**Автор/источник:** Эдуард Ланчев (Ланчев PRO ИИ), ODS/Habr 1070832 (16.08.2026) — кейс сборки «фабрики знаний» из 206 видео / 2,15M слов.
**Суть (2-3 строки):** Единица работы = вопрос (не источник); поверх корпуса строится постоянная *модель знаний* (не базовый RAG); типизированные сущности (Принцип/Правило/Приём/Случай/Несущее-число) + флаг «реконструкция»; provenance-цепочка (фрагмент→выписка→сущность→глава→абзац); отдельный контур факт-проверки; паттерн «важное требование→артефакт/тест».
