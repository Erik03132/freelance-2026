# ivan-ilyich — ИИ-помощник по здоровью на Hermes (референс)

**Автор/источник:** Михаил Коновалов ([vc.ru/AI](https://vc.ru/ai/2867198-ii-doktor-v-telege-vygruzka-analizov-iz-emias-v-claude-code), 14.04.2026) · 28 лайков · публичный кейс.

**Суть (2-3 строки):** Telegram-бот на базе Claude Opus + Claude Code, работает 24/7 на Mac mini. Хранит 7 лет медкарты из ЕМИАС в локальной wiki-папках, отвечает на вопросы по истории, генерит PDF-сводки для врачей, проверяет совместимость лекарств, напоминает о таблетках через cron. Данные не уходят наружу (на личном уровне — на Anthropic; в продуктовой версии — полностью локально).

**Стек (его):**
- Claude Opus ($200/мес максимальная подписка Claude Code)
- Mac mini как сервер, LaunchAgent для авто-старта
- Официальный плагин `telegram-official` в Claude Code
- Whisper large-v3-turbo локально для голосовых
- Ollama + embeddings для семантического поиска по 7-летней базе
- Health Auto Export (iOS) → CSV → объединение в `health-data.csv`
- Pandoc + Chrome headless → PDF-сводки для врача
- CLAUDE.md как точка входа + wiki-структура папок (`doctors/urologist/`, `labs/`)

**Что применимо у нас:** [ДА, ES-11] — у Игоря та же боль: ЕМИАС, анализы, статьи, визиты к врачу. Наша версия = **Айболит** (название от Игоря).

**Чем отличается наш план:**
- Тот же принцип (локальная wiki-папки + семантический поиск + напоминания), но **медленнее** — v0.1 без Telegram/Apple Health, на Hermes Desktop чате.
- Границы: «справочник, не врач», не менять лечение, каждая рекомендация с источником.
- RAG по кардиологии (PubMed Central + ESC/AHA) как закрытие видео Тляшева про холестерин/инфаркт.

**Ключевые грабли автора (полезно знать заранее):**
- Структура папок решает всё: сначала всё в одной папке → агент путал урологию с терапией. Разнесли по специалистам — стало норм.
- Агент считал начало курса лекарства от даты назначения врача, не от фактического приёма → ошибки в напоминаниях. **Правило для нас:** учитывать `start_date` фактического приёма, не `prescribed_date`.
- Реакция врачей — нейтральная или положительная. Одна спросила, остальные просто принимали распечатку.

**Юридическое (если делать выгрузку из ЕМИАС — ES-12):**
- Публичного API ЕМИАС для пациентов **нет** — emias.info/developers даёт API только клиникам-лабораториям
- Автоматизация через браузер (`browser_exec`) может нарушать ToS ЕМИАС. Решение: **спросить Игоря явно** перед запуском массовой выгрузки.

**Приватность:**
- Автор пишет: «мне лично пофиг что данные идут в Anthropic» — но продуктовая версия для клиник = полная локализация (GLM 5.1 / open source модель + Ollama + mlx-whisper). Для нас с самого начала — локально.
