
## 2026-09-23: VPS LLM Proxy Fix — OrcaRouter + trust_env

**Сигнал:** Все LLM-провайдеры недоступны с VPS (российский IP)
**Решение:** US-прокси + OrcaRouter API + trust_env=False

**Ключевые уроки:**
1. `requests.Session(trust_env=False)` — обязательно для VPS, иначе прокси не используется и Authorization header не проходит
2. socks5h:// дает 411, http:// прокси работает корректно
3. OrcaRouter/Nous ключи блокируются после ~20 неудачных попыток — нужно ждать 20-30 минут
4. `_session.post` вместо `requests.post` меняет поведение — нужно тестировать каждый провайдер
5. Бесплатные модели OpenRouter больше не доступны (404), но orcarouter/free работает

**Результат:** Всё настроено, ожидаем разблокировку ключа или новый ключ.
