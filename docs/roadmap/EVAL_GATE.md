# Eval-гейт для контента AI Bureau. Проект

Общий гейт уже есть. Прогон 24.11.2026 дал 17 из 18 suite: падает `eval_ai_scout.py` с результатом 8 из 9. Это baseline до наших правок, коммит и мерж при красном гейте блокируются. Сейф пуст, по RSI-002 это провал.

Падение к AI Bureau отношения не имеет. Кейсы пишет человек с `split=holdout` и `reviewed_by`. Логи находятся в `../audit/gates/`. На 24.11.2026 линтер прошёл по 11 авторским документам. Линтер текста — `tools/ops/content_lint.py`. Он возвращает 1 при находках. Инструмент `tools/geo_lint.py` есть в эталоне. В этом воркспейсе он не внедрялся.

## Что предлагаем добавить

`tests/eval_ai_bureau_content.py`. Проверки детерминированные:

1. У каждой статьи из реестра есть файл и разметка `BlogPosting`. Автор и дата обязательны. AEO-блок занимает 40–60 слов.
2. Три обложки на месте. Все файлы существуют.
3. Реестр проходит проверку. ID уникальны. Переходы статусов корректны. Поле `failed` заполнено причиной. Для `posted` есть URL и дата.
4. Внутренние связи на месте. Статья ведёт на услугу. Услуга ведёт минимум на две статьи.
5. `content_lint.py` возвращает 0 для каждого текста.
6. `llms.txt` совпадает с SSoT услуг. Количество услуг и контакты не расходятся.

## Прогон перед сдачей статьи

```bash
python3 tools/ops/content_lint.py --file docs/distribution/habr/<slug>.md
bash tools/eval_gate.sh --quick
bash tools/eval_gate.sh --holdout
```

Красный гейт означает, что публикация не идёт. Fixed и Verified фиксируются отдельно. Fixed без доказательства статус не подтверждает.

**Статус.** Спецификация только. Файл eval не создан. Сейф не наполнялся. Гейты красные по baseline.
