## Что лежит здесь

Файлы повторяют структуру корня прод-репозитория: копируются в него целиком, без переименований.

- `blog/index.html` — список статей, `Blog` в JSON-LD, ссылка на автора и RSS.
- `blog/ai-agent-ili-chat-bot/index.html` — первая статья: `BlogPosting` + `FAQPage`, канон, автор с фото, услуги по теме, первоисточники.
- `blog/ai-agent-ili-chat-bot/distribution.json` — график выхода на Хабр и в соцсети. Канон — страница сайта; площадки получают адаптацию со ссылкой.
- `author/index.html` — страница автора: `Person` + `ProfilePage`, фото, список текстов. Внешние профили `sameAs` не публикуются до отдельного разрешения.
- `author/igor-vasin.jpg`, `author/igor-vasin@2x.jpg` — фото из `projects/ai-marketing/public/author/`, разрешено Игорем 27.11.2026.
- `sitemap.xml` — 10 URL: главная, 6 услуг, блог, статья, автор.
- `llms.txt` — карта сайта для моделей: услуги, статья, автор, правила цитирования.
- `rss.xml` — лента с полным текстом статьи, формат Дзена `content:encoded`.
- `404.html` — честная 404 вместо текущей выдачи главной на любой путь (AB-TW-4).
