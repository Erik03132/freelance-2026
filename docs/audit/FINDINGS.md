## P0 — чинить до любого контента

### AIB-01. Форма заявки не отправляет лиды
- **Доказательство:** `index.html:1846` — `<form action="/api/submit" method="POST" novalidate>`; `index.html:1877` — `fetch(form.action, …)`; `curl -X POST https://ai-bureau.online/api/submit` → **405**, GET → 404 (GitHub Pages не исполняет API). При неудаче `index.html:1889` показывает «Ошибка отправки. Попробуйте erik03132@gmail.com.», при этом e-mail не является `mailto:` (`index.html:1901`). Цель Метрики `form_submit` (`index.html:1386`) срабатывает на `submit` **до** ответа сервера — отчёт вруёт о конверсии. E-mail в тексте не кликабелен, рабочий канал — только Telegram.
- **Влияние:** 100% заявок через форму теряются; аналитика завышает конверсию. Это единственный встроенный путь лида на сайте.
- **Цена:** 0,5–1 день на Worker/Forms + валидация + цель по успешному ответу. Временный обход без бэкенда — 15 минут: заменить форму на `t.me` deep-link и убрать ложную цель.
- **Приоритет:** P0. **Статус:** Fixed — нет (код не трогался); Verified — да (405, строка кода).

### AIB-07. Нет заголовков безопасности
