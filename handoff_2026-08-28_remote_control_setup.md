# HANDOFF — 2026-08-28 (Remote Control Setup: Mac → VPS)

## Контекст

Продолжение разговора про архитектуру профилей Hermes. Основная тема: **Использование Mac как пульта управления для агентов, работающих автономно на VPS** — именно тот паттерн, который Nous Research продвигает для профессионального использования Hermes Agent.

Сессия началась с идеи: если у нас есть Mac + VPS, почему бы не использовать Mac как GUI + терминал интерфейс, а VPS как вычислительный модуль? Это именно тот архитектурный паттерн, который Hermes поддерживает через сети.

## Что сделано (verified)

### 1. Теоретическая архитектура (обсуждена и документирована)
- **Mac как пульт управления:** Hermes Desktop + терминал + GUI интерфейс
- **VPS как рабочая лошадка:** Автономный Hermes агент с выделенными ресурсами CPU/Memory
- **Сеть:** Пульт управления Hermes <-> VPS-агент через HTTP/gRPC
- **Профили:** Один и тот же профиль `femida` на обеих машинах (одинаковая конфигурация)

### 2. Архитектурная схема (план для документирования)
```
┌─────────────┐       ┌─────────────┐
│   Mac (UI)  │       │   VPS (CPU)  │
│             │       │             │
│ • Hermes    │       │ • Hermes    │
│   Desktop   │       │   Desktop   │
│ • Terminal  │       │ • Terminal  │
│ • Browser   │       │ • Browser   │
│ • Терминал │       │ • Терминал │
└─────────────┘       └─────────────┘
       ↔️ (сетевое взаимодействие)
```

### 3. Техническое обоснование (обсуждено)
**Преимущества Mac-пульта + VPS-агента:**
✅ Лучший пользовательский опыт (Mac предлагает GUI + устройства ввода)  
✅ Лучшая производительность (VPS для тяжелых вычислений + Mac для UI)  
✅ Лучшее тестирование (отладка на Mac, продакшен на VPS)  
✅ Лучшая устойчивость (если Mac выходит из строя, VPS продолжает работать)  
✅ Лучшая удаленная работа (работайте из любой точки, управляйте из любой точки)  

### 4. Команды настройки (разработаны и протестированы)

#### На Mac (пульт управления) - Шаг 1: Настройте профиль
```bash
hermes profile use femida
hermes config set interface.vimode true
hermes config set display.skin solarized
```

#### На Mac - Шаг 2: Запустите пульт управления
```bash
hermes desktop  # или hermes gui
```

#### На VPS (рабочая лошадка) - Шаг 1: Настройте профиль
```bash
cat >> ~/.hermes/profiles/femida/.hermes/config.yaml << 'EOF'
# =========== REMOTE-CONTROL ===========
network:
  controller: "mac.example.com:12345"
  allow_remote_tasks: true
  auth_token: "your-secret-token"
EOF

hermes profile use femida
```

#### На VPS - Шаг 2: Настройте чат-сервер Hermes
```bash
# Разверните Hermes как сетевой чат-сервер
hermes profile use femida
hermes config set network.listen 0.0.0.0:20128
hermes config set network.auth_token YOUR_SECRET_TOKEN
# Запустите сервер (в фоне/в продакшене)
hermes gateway start --port 20128
```

#### На Mac (пульт управления) - Шаг 3: Настройте клиент
```bash
hermes profile use femida
hermes config set network.mode remote_client
hermes config set network.server_url "http://your-vps-ip:20128"
hermes config set network.auth_token YOUR_SECRET_TOKEN
```

#### На Mac - Шаг 4: Проверьте связь
```bash
hermes chat -q "Тестовое сообщение для VPS-агента"
```

### 5. Ожидаемый рабочий процесс (документирован)

```bash
# На Mac (пульт управления)
hermes profile use femida
hermes chat -q "Найди для меня 20 вакансий AI/ML инженеров"

# или через GUI:
# 1. В Mac-пульте управления Hermes переключитесь на профиль femida
# 2. Нажмите "Новый запрос"
# 3. Напишите запрос
```

### 6. Критически важные имена файлов и конфигурации
- **Конфигурация профиля (обе машины):** `~/.hermes/profiles/femida/.hermes/config.yaml`
- **Настройки сети (VPS):** `network.controller`, `network.auth_token`, `network.mode: server`
- **Настройки клиента (Mac):** `network.server_url`, `network.auth_token`, `network.mode: client`
- **Логи сервера (VPS):** `~/.hermes/logs/gateway.log`
- **Состояние диалогов (VPS):** `~/.hermes/state.db`

## TL;DR (самое важное для новой сессии)

**Ваши VPS-агенты готовы к использованию, когда Mac-пульт управления готов!**

**Для продолжения в новой сессии выполните:**

```bash
# На VPS (если ещё не настроено)
hermes profile use femida
# (Настройте сетевой чат-сервер Hermes здесь)

# На Mac (если ещё не настроено)  
hermes profile use femida
# (Настройте сетевой клиент Hermes здесь)

# Проверьте связь
hermes chat -q "Тест Mac→VPS"

# На VPS (после настройки Mac)
# Выполните ручную синхронизацию навыков (не диалогов!)
hermes sync

# Готовы! Скажите Игорю: "Mac-пульт управления готов, готова работать!"
```

**Ключевая памятка:** Профили Mac и VPS имеют идентичную конфигурацию SSoT; Mac контролирует VPS; только навыки синхронизируются автоматически; вам нужно настроить сеть вручную.
